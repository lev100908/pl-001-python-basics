# Создание множеств

> **Главная мысль.** Множество создают тремя способами: **литералом**
> `{элемент, ...}`, вызовом **`set()`** (из любого итерируемого объекта; без
> аргументов — пустое множество) и **включением**
> `{выражение for ... in ...}`.
> Пустое множество можно создать **только** через `set()`: запись `{}`
> создает пустой *словарь*. Во всех случаях элементы должны быть
> хешируемыми, а дубликаты автоматически отбрасываются.

---

## 1. Литералы множеств

**Литерал множества** — элементы через запятую в фигурных скобках. Повторы
отбрасываются:

```python
primes = {2, 3, 5, 7}
letters = {"a", "b", "a", "c"}

print(primes)   # {2, 3, 5, 7}
print(letters)  # {'a', 'b', 'c'} -- порядок вывода может быть другим
```

Порядок вывода элементов множества не определен, поэтому в примерах он
может отличаться от того, что вы увидите на своем компьютере.

### Пустое множество

Пустые фигурные скобки `{}` — это литерал **пустого словаря**, а не множества.
Это историческая особенность: фигурные скобки сначала были закреплены за
словарями. Чтобы создать пустое множество, нужно вызвать `set()`:

```python
empty_dict = {}
empty_set = set()

print(type(empty_dict))  # <class 'dict'>
print(type(empty_set))   # <class 'set'>
print(empty_set)         # set() -- именно так выводится пустое множество
```

---

## 2. Создание с помощью `set()`

`set(iterable)` создает множество из элементов **любого итерируемого
объекта**: списка, кортежа, строки, словаря (будут взяты ключи), другого
множества, генератора и т. д. Повторяющиеся элементы попадут в множество
один раз:

```python
numbers_set = set([1, 2, 2, 3])
letters_set = set("hello")
keys_set = set({"a": 1, "b": 2})

print(numbers_set)  # {1, 2, 3}
print(letters_set)  # {'h', 'e', 'l', 'o'} -- порядок может отличаться
print(keys_set)     # {'a', 'b'} -- из словаря взяты ключи
```

Вызов `set()` без аргументов создает пустое множество (см. выше).

`set()` принимает **ровно один** аргумент — итерируемый объект. Нельзя
передать элементы через запятую, а также передать неитерируемый объект:

```python
set(1, 2, 3)
# TypeError: set expected at most 1 argument, got 3

set(42)
# TypeError: 'int' object is not iterable
```

Если нужно создать множество из нескольких отдельных значений, используйте
литерал `{1, 2, 3}` или передайте их в `set()` в виде списка/кортежа:
`set([1, 2, 3])`.

Важное отличие литерала от `set()` на примере строки: литерал рассматривает
строку как **один элемент**, а `set()` — как последовательность символов:

```python
print({"hello"})     # {'hello'}
print(set("hello"))  # {'h', 'e', 'l', 'o'} -- порядок может отличаться
```

`set()` — также привычный способ скопировать множество или превратить
в множество другую коллекцию. Если элементы нехешируемые, возникнет
`TypeError`:

```python
set([[1, 2], [3, 4]])
# TypeError: unhashable type: 'list'
```

## 3. Включения множеств

**Включение множества (set comprehension)** — компактная запись
создания множества. Синтаксис такой же, как у спискового включения, но в
фигурных скобках:

```python
squares = {number ** 2 for number in range(-3, 4)}

print(squares)  # {0, 1, 4, 9} -- порядок может отличаться; повторы убраны
```

Здесь выражение `number ** 2` для чисел от -3 до 3 дает повторяющиеся
значения (например, `(-2) ** 2` и `2 ** 2` — оба `4`), но в множестве каждое
значение окажется один раз. Условие `if` работает так же, как в
списковых включениях:

```python
words = ["apple", "avocado", "banana", "blueberry", "apple"]

first_letters = {word[0] for word in words}
long_words = {word for word in words if len(word) > 5}

print(first_letters)  # {'a', 'b'} -- порядок может отличаться
print(long_words)     # {'avocado', 'banana', 'blueberry'} -- порядок может отличаться
```

Включение — это способ получить уникальные значения, одновременно применив
к ним преобразование или фильтр.

---

## Вывод

- Множество создается литералом `{1, 2, 3}`, вызовом `set(iterable)` и
  включением `{выражение for ... in ...}`.
- **Пустое множество** создается только через `set()`: `{}` — это пустой
  словарь.
- `set(iterable)` принимает один итерируемый объект: строка превращается в
  множество символов, словарь — в множество ключей. Дубликаты отбрасываются.
- Элементы всегда должны быть хешируемыми; порядок элементов у
  получившегося множества не определен.
