# Создание словарей

> **Главная мысль.** Словарь можно создать четырьмя способами: **литералом**
> `{ключ: значение, ...}`, **словарным включением**
> `{ключ: значение for ... in ...}`, **вызовом `dict()`** (из именованных
> аргументов, из другого словаря, из итерируемого объекта пар) и методом
> **`dict.fromkeys()`**, который создает словарь с одним и тем же значением
> для всех ключей. Во всех способах ключи должны быть **хешируемыми**. Метод
> `dict.fromkeys()` с изменяемым значением по умолчанию приводит к
> неожиданному поведению: все ключи указывают на **один и тот же** объект.

---

## 1. Словарные литералы

**Литерал словаря** — это запись пар «ключ: значение» через запятую внутри
фигурных скобок. Пустые фигурные скобки `{}` создают **пустой словарь**:

```python
empty_dict = {}
user = {"name": "Alice", "age": 25}
square_roots = {1: 1.0, 4: 2.0, 9: 3.0}

print(empty_dict)    # {}
print(user)          # {'name': 'Alice', 'age': 25}
print(square_roots)  # {1: 1.0, 4: 2.0, 9: 3.0}
```

Для удобочитаемости литерал с большим количеством пар принято записывать
в несколько строк — по одной паре на строку, с запятой после каждой пары:

```python
config = {
    "host": "localhost",
    "port": 8080,
    "debug": True,
}
```

### Ключи должны быть хешируемыми

**Ключом** словаря может быть только **хешируемый** объект (см. конспект про
хеш-функции): число, строка, логическое значение, `None`, кортеж из
хешируемых элементов. Значением может быть что угодно. При попытке
использовать нехешируемый объект в качестве ключа возникает `TypeError`:

```python
valid_dict = {(1, 2): "point"}  # кортеж -- хешируемый ключ

print(valid_dict[(1, 2)])       # point

invalid_dict = {[1, 2]: "point"}
# TypeError: unhashable type: 'list'
```

### Повторяющиеся ключи

Ключи в словаре уникальны. Если в литерале один и тот же ключ указан
несколько раз, ошибки не будет: в словаре останется **последнее** значение,
а позиция ключа определяется его **первой** записью:

```python
duplicated_dict = {"a": 1, "b": 2, "a": 3}

print(duplicated_dict)  # {'a': 3, 'b': 2}
```

То же происходит с ключами, которые равны друг другу, даже если они разных
типов: `1`, `1.0` и `True` — это один и тот же ключ, потому что они равны и
имеют одинаковый хеш:

```python
print({1: "int", 1.0: "float", True: "bool"})  # {1: 'bool'}
```

## 2. Словарные включения

**Словарное включение (dict comprehension)** — компактная запись создания
словаря из итерируемого объекта; по синтаксису оно аналогично списковому
включению, но записывается в фигурных скобках, а выражение состоит из пары
`ключ: значение`:

```python
squares = {number: number ** 2 for number in range(1, 6)}

print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

В конце можно добавить условие `if`, которое отфильтрует элементы
исходного объекта:

```python
even_squares = {number: number ** 2 for number in range(1, 11) if number % 2 == 0}

print(even_squares)  # {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

Включение удобно использовать, чтобы построить словарь из других
коллекций — например, «перевернуть» словарь (поменять ключи и значения
местами; значения при этом должны быть хешируемыми и уникальными) или
преобразовать значения:

```python
prices = {"apple": 100, "banana": 60}

doubled_prices = {name: price * 2 for name, price in prices.items()}
inverted_prices = {price: name for name, price in prices.items()}

print(doubled_prices)   # {'apple': 200, 'banana': 120}
print(inverted_prices)  # {100: 'apple', 60: 'banana'}
```

Метод `items()` рассмотрен в конспекте про методы итерирования.

## 3. Создание словаря с помощью `dict()`

`dict` — это не только имя типа данных, но и **вызываемый объект**, создающий
словарь. В зависимости от переданных аргументов существует несколько
способов создания.

### Без аргументов

Создает пустой словарь, то же самое, что и `{}`:

```python
empty_dict = dict()

print(empty_dict)  # {}
```

### Из именованных аргументов

Имена аргументов становятся **строковыми ключами**, переданные значения —
значениями словаря:

```python
user = dict(name="Alice", age=25)

print(user)  # {'name': 'Alice', 'age': 25}
```

Ограничение: ключи в этом случае — только строки, причем такие, которые
допустимы как имена переменных (нельзя использовать, например, `"first-name"`
или число `1`).

### Из другого словаря

Создается **новый** словарь (поверхностная копия) с теми же парами:

```python
original = {"a": 1, "b": 2}
copied = dict(original)

copied["c"] = 3

print(original)  # {'a': 1, 'b': 2}
print(copied)    # {'a': 1, 'b': 2, 'c': 3}
```

### Из итерируемого объекта пар

Можно передать любой итерируемый объект (список, кортеж, генератор и т. д.),
каждый элемент которого — **пара** из двух элементов (ключ и значение):

```python
pairs = [("name", "Alice"), ("age", 25)]

print(dict(pairs))  # {'name': 'Alice', 'age': 25}
```

Если элемент — не пара из двух значений, будет возбуждена ошибка:

```python
print(dict([("a", 1, 2)]))
# ValueError: dictionary update sequence element #0 has length 3; 2 is required
```

### Комбинация: словарь или пары и именованные аргументы

Первым позиционным аргументом можно передать словарь (или итерируемый
объект пар), а следом — дополнительные именованные аргументы. Они будут
добавлены в словарь (а если ключ уже есть, его значение будет заменено):

```python
base = {"a": 1, "b": 2}

print(dict(base, c=3))    # {'a': 1, 'b': 2, 'c': 3}
print(dict(base, a=100))  # {'a': 100, 'b': 2}
```

Позиционный аргумент у `dict()` можно передать **только один**.

## 4. Метод `dict.fromkeys()`

`dict.fromkeys(iterable, value=None)` — метод типа `dict`, который создает
словарь, ключами которого становятся элементы итерируемого объекта
`iterable`, а **все значения одинаковы** и равны `value`. Если `value` не
указано, значением по умолчанию будет `None`. Вызывается метод от имени
типа `dict`, а не от имени конкретного словаря:

```python
keys = ["a", "b", "c"]

print(dict.fromkeys(keys))     # {'a': None, 'b': None, 'c': None}
print(dict.fromkeys(keys, 0))  # {'a': 0, 'b': 0, 'c': 0}
```

Метод удобен для начальной инициализации словаря: например, завести
счетчики, равные нулю, для всех известных ключей.

### Подвох с изменяемым значением

Значение `value` вычисляется **один раз**, и **один и тот же объект**
записывается в качестве значения для всех ключей. Для неизменяемых значений
(`0`, `None`, строка) это безопасно. Но если передать изменяемый объект —
например, список — то все ключи будут ссылаться на один и тот же список:

```python
shared_dict = dict.fromkeys(["a", "b", "c"], [])

shared_dict["a"].append(1)

print(shared_dict)  # {'a': [1], 'b': [1], 'c': [1]} -- а ожидали [1], [], []

print(shared_dict["a"] is shared_dict["b"])  # True -- это один и тот же список
```

Если для каждого ключа нужен **свой** изменяемый объект, используйте
словарное включение — в нем выражение для значения вычисляется заново для
каждого ключа:

```python
separate_dict = {key: [] for key in ["a", "b", "c"]}

separate_dict["a"].append(1)

print(separate_dict)  # {'a': [1], 'b': [], 'c': []}
```

---

## Вывод

- Словарь создается **литералом** `{...}` (пустой — `{}`), **словарным
  включением**, вызовом **`dict()`** и методом **`dict.fromkeys()`**.
- Ключи — только **хешируемые** объекты, иначе `TypeError`. Повторяющийся
  ключ в литерале не вызывает ошибки: сохраняется последнее значение;
  ключи `1`, `1.0` и `True` считаются одним и тем же ключом.
- `dict()` умеет создавать словарь из именованных аргументов, из другого
  словаря (копия) и из итерируемого объекта пар.
- `dict.fromkeys(keys, value)` задает всем ключам **один и тот же** объект
  `value`. С изменяемым значением (например, `[]`) все ключи будут
  ссылаться на один объект; для отдельных объектов используйте словарное
  включение.
