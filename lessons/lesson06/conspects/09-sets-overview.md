# Множество: обзор и характеристики

> **Главная мысль.** `set` — встроенный **составной** тип данных, моделирующий
> математическое **множество**: набор **уникальных** элементов. Элементы
> множества должны быть **хешируемыми**, а их порядок **не определен** —
> индексов у множества нет. Множество **гетерогенно**, **ограничено**
> (`len()` возвращает количество элементов), **изменяемо** и **итерируемо**.
> Благодаря хеш-таблице проверка «есть ли элемент в множестве» выполняется
> почти мгновенно, поэтому множества используют для удаления дубликатов и
> быстрых проверок на принадлежность.

---

## 1. Множество — коллекция уникальных элементов

`set` — это коллекция, в которой каждый элемент встречается **не более
одного раза**. Если добавить в множество элемент, который в нем уже есть,
множество не изменится. Внутри множество устроено как хеш-таблица —
подобно словарю, но хранит только ключи, без значений.

```python
numbers = {1, 2, 2, 3, 3, 3}

print(numbers)       # {1, 2, 3} -- дубликаты исчезли
print(len(numbers))  # 3
```

Множества не стоит путать со списками и словарями:

| | `list` | `dict` | `set` |
|---|---|---|---|
| Что хранит | элементы | пары «ключ — значение» | уникальные элементы |
| Повторы | допустимы | ключи уникальны | недопустимы |
| Доступ к элементу | по индексу | по ключу | **нет** (только проверка наличия) |
| Порядок | есть | порядок вставки | **не определен** |

## 2. Характеристики множества

### Гетерогенность

Множество **гетерогенно**: в нем могут одновременно лежать элементы разных
типов, но только **хешируемые** (см. конспект про хеш-функции):

```python
mixed_set = {42, "hello", 3.14, True, None, (1, 2)}

print(len(mixed_set))  # 6
```

### Элементы должны быть хешируемыми

Поскольку множество устроено как хеш-таблица, его элементами могут быть
только **хешируемые** объекты — числа, строки, `bool`, `None`, кортежи из
хешируемых элементов и т. д. Изменяемые объекты — списки, словари, другие
множества — в множество положить нельзя:

```python
valid_set = {(1, 2), "a"}  # кортеж -- хешируемый, можно

invalid_set = {[1, 2], "a"}
# TypeError: unhashable type: 'list'
```

Из-за этого же множество не может быть элементом другого множества.
Для таких случаев существует неизменяемая разновидность множества —
`frozenset` (она хешируема).

Как и для ключей словаря, объекты, которые **равны** друг другу и имеют
**одинаковый хеш**, считаются одним и тем же элементом, даже если у них
разные типы: `1`, `1.0` и `True` в множестве будут одним элементом:

```python
print({1, 1.0, True})  # {1}
```

### Ограниченность

Множество **ограничено**: количество его элементов конечно и возвращается
функцией `len()`:

```python
colors = {"red", "green", "blue"}

print(len(colors))  # 3
print(len(set()))   # 0
```

### Неупорядоченность

В отличие от списка и словаря, множество **неупорядочено**: Python не
гарантирует, в каком порядке элементы будут выдаваться при выводе или
переборе, и порядок не обязан совпадать с порядком добавления. По этой же
причине у множества **нет индексов и срезов** — обратиться к элементу
по номеру позиции невозможно:

```python
colors = {"red", "green", "blue"}

print(colors[0])
# TypeError: 'set' object is not subscriptable
```

Порядок вывода может отличаться от запуска к запуску: в частности, порядок
строк зависит от их хешей, которые случайным образом меняются при каждом
запуске программы. Поэтому на порядок элементов множества нельзя
полагаться — если порядок важен, используйте список (например, `sorted(my_set)`
вернет отсортированный список элементов).

Из-за неупорядоченности два множества с одинаковыми элементами равны,
независимо от того, в каком порядке они были записаны:

```python
print({1, 2, 3} == {3, 2, 1})  # True
```

### Изменяемость

Множество **изменяемо (mutable)**: после создания в него можно добавлять
элементы и удалять их, при этом идентичность объекта (`id()`) не меняется:

```python
tags = {"python", "code"}
identity_before = id(tags)

tags.add("study")

print(len(tags))                    # 3
print(id(tags) == identity_before)  # True -- это все еще тот же объект
```

Менять *сам* элемент множества нельзя: элементы — хешируемые, как правило
неизменяемые, объекты. Можно удалить старый элемент и добавить новый.

### Итерируемость

Множество **итерируемо** — его можно перебирать в цикле `for`, помня о том,
что порядок обхода не определен:

```python
colors = {"red", "green", "blue"}

for color in colors:
    print(color)
```

Порядок вывода может быть любым, например:
```
green
red
blue
```

## 3. В каких задачах используются множества

- **удаление дубликатов** — получить уникальные значения из
  последовательности (порядок элементов при этом не сохраняется);
- **быстрая проверка принадлежности** — `element in my_set` работает за
  примерно постоянное время, как поиск ключа в словаре, и гораздо быстрее
  аналогичного поиска в списке;
- **подсчет количества уникальных значений** — `len(set(items))`;
- **теоретико-множественные операции** — объединение, пересечение, разность
  множеств (будут рассмотрены на семинаре): например, найти общих
  подписчиков двух каналов или тех, кто есть в первом, но отсутствует во
  втором.

Пример удаления дубликатов:

```python
numbers = [1, 2, 2, 3, 3, 3, 1]
unique_numbers = list(set(numbers))

print(len(unique_numbers))  # 3
```

---

## Вывод

- `set` — составной тип данных, хранящий **уникальные** элементы. Внутри
  устроен как хеш-таблица, как и словарь.
- Элементы множества должны быть **хешируемыми**: изменяемые объекты
  (`list`, `dict`, `set`) добавить нельзя.
- Множество **гетерогенно**, **ограничено** (`len()`), **изменяемо** и
  **итерируемо**, но **неупорядочено**: у него нет индексов и срезов,
  порядок обхода не определен.
- Множества используют для удаления дубликатов, быстрой проверки
  принадлежности и теоретико-множественных операций.
