# Изменение и добавление элементов словаря

> **Главная мысль.** Добавление новой пары и изменение значения
> существующей выполняются одной и той же операцией — присваиванием по
> ключу `my_dict[key] = value`: если ключа нет, пара добавляется, если есть —
> значение заменяется. Несколько пар за раз добавляет метод
> **`update()`**, который **изменяет** словарь на месте. Оператор **`|`**
> объединяет два словаря в **новый**, а `|=` работает как `update()`. При
> совпадении ключей побеждает значение **из правого** операнда (или
> аргумента).

---

## 1. Изменение и добавление через квадратные скобки

Запись `my_dict[key] = value` работает по принципу «обновить или создать»:

- если ключ `key` **уже есть** — его значение заменяется на `value`;
- если ключа **нет** — в словарь добавляется новая пара `key: value`.

```python
user = {"name": "Alice", "age": 25}

user["age"] = 26        # такой ключ есть -- значение заменено
user["city"] = "Paris"  # такого ключа нет -- пара добавлена

print(user)  # {'name': 'Alice', 'age': 26, 'city': 'Paris'}
```

Ошибки `KeyError` при присваивании не бывает — в отличие от чтения.

Влияние на порядок:

- замена значения существующего ключа **не меняет** позицию ключа;
- новый ключ добавляется **в конец** словаря.

Как и при создании, ключ должен быть **хешируемым**, иначе будет
`TypeError`.

---

## 2. Метод `update()`

`my_dict.update(other)` добавляет в словарь все пары из `other`. Если ключ
уже есть в словаре, его значение **заменяется** на значение из `other`;
если ключа нет — пара добавляется. Метод **изменяет сам словарь** и
возвращает `None`. Аргумент можно передать в нескольких вариантах — те же,
что и у `dict()`:

```python
user = {"name": "Alice", "age": 25}

# другой словарь
user.update({"age": 26, "city": "Paris"})

print(user)  # {'name': 'Alice', 'age': 26, 'city': 'Paris'}

# итерируемый объект пар
user.update([("job", "engineer"), ("age", 27)])

print(user)  # {'name': 'Alice', 'age': 27, 'city': 'Paris', 'job': 'engineer'}

# именованные аргументы
user.update(city="Berlin", active=True)

print(user)  # {'name': 'Alice', 'age': 27, 'city': 'Berlin', 'job': 'engineer', 'active': True}
```

Так как `update()` возвращает `None`, результат метода не нужно
присваивать переменной — это распространенная ошибка:

```python
user = {"name": "Alice"}

result = user.update({"age": 25})

print(result)  # None
print(user)    # {'name': 'Alice', 'age': 25} -- обновился сам user
```

## 3. Оператор `|`

Начиная с **Python 3.9** словари можно объединять оператором `|`. Он создает
**новый словарь**, в который сначала попадают пары из левого операнда, а
затем — из правого. Если ключ есть в обоих словарях, побеждает значение
**из правого** словаря. Исходные словари при этом **не изменяются**:

```python
defaults = {"theme": "light", "font_size": 12}
custom = {"font_size": 16, "language": "en"}

merged = defaults | custom

print(merged)    # {'theme': 'light', 'font_size': 16, 'language': 'en'}
print(defaults)  # {'theme': 'light', 'font_size': 12} -- не изменился
print(custom)    # {'font_size': 16, 'language': 'en'} -- не изменился
```

Оператор `|=` обновляет левый словарь и работает как
`update()` — в том числе принимает не только словарь, но и итерируемый
объект пар:

```python
settings = {"theme": "light", "font_size": 12}

settings |= {"font_size": 16}
settings |= [("language", "en")]

print(settings)  # {'theme': 'light', 'font_size': 16, 'language': 'en'}
```

### `update()`, `|` и `|=`

| Способ | Меняет исходный словарь? | Что возвращает |
|---|---|---|
| `my_dict.update(other)` | да | `None` |
| `my_dict \| other` | нет | новый словарь |
| `my_dict \|= other` | да | тот же словарь (обновленный) |

Оператор `|` удобен, когда нужен словарь «значения по умолчанию +
пользовательские настройки», но исходные словари нужно сохранить
неизменными. `update()` и `|=` экономнее по памяти, так как не создают
новый словарь.

---

## Вывод

- `my_dict[key] = value` добавляет пару (ключа нет) или заменяет значение
  (ключ есть). Позиция существующего ключа не меняется, новый ключ
  попадает в конец.
- `my_dict.update(other)` добавляет/обновляет сразу много пар из словаря,
  итерируемого объекта пар или именованных аргументов; изменяет словарь на
  месте и возвращает `None`.
- `first | second` (Python 3.9+) возвращает **новый** словарь; при
  совпадении ключей побеждает значение из правого операнда. `|=` работает
  как `update()`.
