# Хеш-функции и хешируемость

> **Главная мысль.** **Хеш-функция** превращает объект в целое число —
> **хеш** — фиксированного размера. Словари и множества используют хеши,
> чтобы находить элементы практически мгновенно, поэтому ключи словаря и
> элементы множества должны быть **хешируемыми**. В Python хеш объекта
> возвращает встроенная функция `hash()`. Как правило, хешируемы
> **неизменяемые** объекты (`int`, `float`, `bool`, `str`, `None`, кортежи
> из хешируемых элементов), а изменяемые (`list`, `dict`, `set`) —
> нехешируемы.

---

## 1. Что такое хеш-функция

**Хеш-функция** — это функция, которая принимает на вход данные произвольного
размера (число, строку, любой другой объект) и возвращает целое число
(**хеш**) фиксированного размера. Для одинаковых входных данных хеш всегда
одинаков, а для разных данных — как правило, различен (редкие случаи, когда у
разных объектов хеш совпал, называются **коллизиями**). Главное свойство
хеш-функции — она вычисляется быстро, а по хешу можно сразу понять, *где
искать* объект. Именно на этом построена работа словарей и множеств:
Python вычисляет хеш ключа и по нему сразу находит место, где хранится
соответствующее значение, не перебирая все элементы подряд. Такая структура
данных называется **хеш-таблицей**.

---

## 2. Встроенная функция `hash()`

Функция `hash(obj)` возвращает хеш объекта в виде целого числа:

```python
print(hash(42))       # 42
print(hash(True))     # 1
print(hash("hello"))  # некоторое большое целое число
```

Что важно знать о значениях, которые возвращает `hash()`:

- у **равных** объектов хеши **обязаны совпадать**: если `first == second`,
  то и `hash(first) == hash(second)`. Поэтому хеши `3` и `3.0` совпадают, ведь
  `3 == 3.0`;
- хеш **строки** (а также `bytes`) случайным образом меняется от запуска к
  запуску программы (так сделано из соображений безопасности), поэтому
  нельзя ни сохранять его, ни рассчитывать на конкретное значение.

```python
print(hash(3) == hash(3.0))  # True -- 3 == 3.0, значит хеши равны
```

---

## 3. Хешируемость

Объект называется **хешируемым (hashable)**, если:

1. у него есть хеш, который **не меняется** в течение всей жизни объекта;
2. его можно сравнивать с другими объектами на равенство.

Для встроенных типов эти условия сводятся к простому правилу:

> **хешируемы неизменяемые объекты, нехешируемы — изменяемые.**

Причина проста. Хеш вычисляется по *содержимому* объекта. Если бы
изменяемый объект (например, список) можно было использовать как ключ,
то после изменения его содержимого изменился бы и хеш, и Python уже не смог
бы найти то место, где хранится ключ: словарь «потерял» бы свои данные.
Чтобы этого не происходило, изменяемые объекты запрещено использовать как
ключи.

Если попробовать получить хеш нехешируемого объекта, возникает `TypeError`:

```python
print(hash([1, 2, 3]))
# TypeError: unhashable type: 'list'
```

(В новых версиях Python текст сообщения может быть расширен, но слова
`unhashable type` в нем остаются.)

### Примеры хешируемых объектов

| Тип | Пример | Хешируем? |
|---|---|---|
| `int` | `42` | да |
| `float` | `3.14` | да |
| `bool` | `True` | да |
| `str` | `"hello"` | да |
| `NoneType` | `None` | да |
| `tuple` из хешируемых элементов | `(1, 2, "a")` | да |
| `frozenset` | `frozenset({1, 2})` | да |

### Примеры нехешируемых объектов

| Тип | Пример | Хешируем? |
|---|---|---|
| `list` | `[1, 2, 3]` | нет |
| `dict` | `{"a": 1}` | нет |
| `set` | `{1, 2, 3}` | нет |
| `tuple`, содержащий нехешируемый элемент | `(1, [2, 3])` | нет |

Последний пример показывает, что хешируемость кортежа зависит от его
содержимого: кортеж сам по себе неизменяем, но хеш кортежа вычисляется из
хешей всех его элементов, а если среди них есть список, получить хеш не
получится:

```python
print(hash((1, 2, 3)))
# хеш успешно вычислен

print(hash((1, [2, 3])))
# TypeError: unhashable type: 'list'
```

`frozenset` — «замороженная» (неизменяемая) разновидность множества,
подробнее о ней речь пойдет в конспектах про множества.

---

## Вывод

- **Хеш-функция** превращает объект в целое число; на хешах построены
  словари и множества (хеш-таблицы), что позволяет находить элементы без
  перебора.
- Встроенная функция `hash()` возвращает хеш объекта. Равные объекты
  обязаны иметь равные хеши; хеши строк меняются от запуска к запуску.
- Ключи словаря и элементы множества должны быть **хешируемыми**. Хешируемы
  неизменяемые объекты (`int`, `float`, `bool`, `str`, `None`, `frozenset`,
  кортежи из хешируемых элементов), нехешируемы изменяемые (`list`, `dict`,
  `set`).
- Попытка получить хеш нехешируемого объекта приводит к
  `TypeError: unhashable type`.
