# Словарь: обзор и характеристики

> **Главная мысль.** `dict` — встроенный **составной** тип данных, который
> хранит набор пар **«ключ — значение»** и позволяет быстро получать значение
> по ключу. Словарь **гетерогенен** (и ключи, и значения могут быть разных
> типов), **ограничен** (количество пар можно узнать через `len()`),
> **упорядочен** (начиная с Python 3.7 пары хранятся в порядке вставки),
> **изменяем** и **итерируем**. Словари применяют везде, где данные нужно
> искать не по номеру позиции, а по осмысленному имени, а сам Python
> использует словари «под капотом» для хранения атрибутов объектов и
> модулей.

---

## 1. Словарь — отображение «ключ → значение»

В списке элемент находится по **индексу** — целому числу, определяющему
положение элемента. Словарь устроен иначе: каждый элемент — это **пара**,
состоящая из **ключа (key)** и связанного с ним **значения (value)**.
Значение достается не по номеру позиции, а по ключу. Такие типы данных
называют **отображениями (mapping)**: они *отображают* ключи на значения.

```python
user = {"name": "Alice", "age": 25, "city": "Paris"}

print(user["name"])  # Alice -- значение по ключу "name"
print(user["age"])   # 25
```

Ключи в словаре **уникальны**: два одинаковых ключа в одном словаре
существовать не могут — у каждого ключа ровно одно значение. Значения же
могут повторяться сколько угодно раз.

## 2. Характеристики словаря

### Гетерогенность

Словарь **гетерогенен**: в одном словаре могут одновременно храниться
значения разных типов данных — числа, строки, списки, другие словари и
любые другие объекты. Ключи тоже могут быть разных типов (при условии, что
они *хешируемы* — подробнее в следующем конспекте):

```python
mixed_dict = {
    "name": "Alice",           # ключ-строка, значение-строка
    "scores": [90, 85],        # значение-список
    42: "answer",              # ключ-число
    (1, 2): {"nested": True},  # ключ-кортеж, значение-словарь
}

print(mixed_dict)
# {'name': 'Alice', 'scores': [90, 85], 42: 'answer', (1, 2): {'nested': True}}
```

Как и в случае со списком, гетерогенность — возможность, а не требование.
На практике ключи, как правило, одного типа (чаще всего строки), а значения
либо одного типа, либо описывают разные свойства одного объекта, как в
примере со словарем `user` выше.

### Ограниченность

Словарь **ограничен** — в любой момент времени он хранит конкретное,
конечное количество пар «ключ — значение». Функция `len()` возвращает
именно количество **пар**:

```python
user = {"name": "Alice", "age": 25, "city": "Paris"}

print(len(user))  # 3
print(len({}))    # 0
```

### Упорядоченность

Начиная с версии **Python 3.7** словарь **сохраняет порядок вставки**: пары
хранятся и выдаются в том порядке, в котором ключи были добавлены в словарь.
В более ранних версиях порядок пар не гарантировался.

```python
ordered_dict = {}

ordered_dict["first"] = 1
ordered_dict["second"] = 2
ordered_dict["third"] = 3

print(ordered_dict)  # {'first': 1, 'second': 2, 'third': 3}
```

Важно понимать, что упорядоченность словаря **не такая же, как у списка**:
у пар нет индексов, и обратиться к паре по номеру позиции нельзя — доступ
всегда идет по ключу. Порядок вставки определяет лишь то, в какой
последовательности пары будут выданы при итерировании или выводе. Кроме
того, при сравнении двух словарей через `==` порядок пар **не учитывается**:

```python
first_dict = {"a": 1, "b": 2}
second_dict = {"b": 2, "a": 1}

print(first_dict == second_dict)  # True -- порядок пар не влияет на равенство
print([1, 2] == [2, 1])           # False -- для списков порядок важен
```

### Изменяемость

Словарь **изменяем (mutable)**: после создания в него можно добавлять новые
пары, менять значения существующих и удалять пары. Объект словаря при этом
остается тем же самым (его идентичность, которую возвращает `id()`, не
меняется):

```python
scores = {"math": 90}
identity_before = id(scores)

scores["physics"] = 85
scores["math"] = 95

print(scores)                         # {'math': 95, 'physics': 85}
print(id(scores) == identity_before)  # True -- это все еще тот же объект
```

### Итерируемость

Словарь **итерируем**: его можно обойти в цикле `for`. При обычном обходе
словаря получаются его **ключи**, в порядке вставки:

```python
user = {"name": "Alice", "age": 25, "city": "Paris"}

for key in user:
    print(key)
```

Вывод:
```
name
age
city
```

Остальные способы обхода словаря (по значениям и по парам) рассмотрены в
конспекте про методы итерирования.

## 3. В каких задачах используются словари

Словарь — естественный выбор, когда данные нужно **искать по имени или
идентификатору**, а не по номеру позиции. Типичные случаи:

- **описание одного объекта с набором свойств** — пользователь, товар,
  настройки программы: `{"name": "Alice", "age": 25}`;
- **таблицы соответствий (lookup tables)** — код страны → название, имя
  команды → ее описание, оценка в баллах → оценка в буквах;
- **подсчет и группировка** — сколько раз встретилось каждое слово в тексте
  (слово → счетчик), какие товары относятся к каждой категории
  (категория → список товаров);
- **быстрый доступ по идентификатору** — идентификатор пользователя → его
  данные;
- **обмен данными между программами** — формат JSON, который широко
  используется в веб-сервисах и конфигурационных файлах, по структуре
  практически совпадает со словарями и списками Python.

Пример — подсчет количества каждого символа в строке:

```python
text = "banana"
letters_count = {}

for letter in text:
    letters_count[letter] = letters_count.get(letter, 0) + 1

print(letters_count)  # {'b': 1, 'a': 3, 'n': 2}
```

(Метод `get` рассмотрен в конспекте про чтение элементов словаря.)

## 4. Словарь как фундаментальный тип Python

Словари важны не только для программиста, но и для самого интерпретатора:
на словарях построены многие внутренние механизмы Python. Например:

- **глобальные переменные модуля** хранятся в словаре, где ключ — имя
  переменной, а значение — связанный с ним объект; получить его можно через
  функцию `globals()`;
- **атрибуты объектов** (в том числе модулей и экземпляров классов) также
  хранятся в словаре, доступном через специальный атрибут `__dict__`;
- **именованные аргументы функции** собираются в словарь при использовании
  конструкции `**kwargs` (эта тема будет рассмотрена при изучении функций).

```python
counter = 10

print(type(globals()))       # <class 'dict'>
print(globals()["counter"])  # 10 -- переменная модуля лежит в словаре


class Point:
    def __init__(self) -> None:
        self.x_coordinate = 1
        self.y_coordinate = 2


point = Point()

print(point.__dict__)  # {'x_coordinate': 1, 'y_coordinate': 2}
```

Именно поэтому доступ к переменным и атрибутам в Python работает быстро:
поиск по ключу в словаре — одна из самых оптимизированных операций языка.

---

## Вывод

- `dict` — составной тип данных, хранящий пары «ключ — значение»; значение
  достается по ключу, а не по индексу. Ключи в словаре уникальны.
- Словарь **гетерогенен**, **ограничен** (`len()` возвращает количество пар),
  **упорядочен** (с Python 3.7 сохраняется порядок вставки), **изменяем**
  и **итерируем** (по умолчанию обход идет по ключам).
- Порядок пар не учитывается при сравнении словарей и не дает доступа по
  индексу.
- Словари применяют для описания объектов со свойствами, таблиц
  соответствий, подсчета и группировки, быстрого поиска по идентификатору.
- На словарях построены внутренние механизмы самого Python: переменные
  модуля, атрибуты объектов (`__dict__`), `**kwargs`.
