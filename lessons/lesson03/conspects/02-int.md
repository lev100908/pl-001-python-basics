# Целочисленный тип данных `int`

> **Главная мысль.** `int` — тип для представления целых чисел. Создать значение можно
> литералом в разных системах счисления или конструктором `int()`, в том
> числе с явным указанием основания системы счисления. У `int` в Python
> **нет ограничения на диапазон значений** — под большие числа интерпретатор
> сам выделяет столько памяти, сколько нужно.

---

## 1. Создание объекта целых чисел с помощью литералов

Самый простой способ создать объект целочисленного типа — просто использовать
десятичное число в коде:

```python
positive_number = 42
negative_number = -17
zero_number = 0
```

---

## 2. Виды литералов

### Обычный десятичный литерал

Десятичный литерал — это просто последовательность цифр `0-9`, записанная
подряд. Знак `-` перед числом (`-17`) в грамматику литерала не входит —
это отдельный унарный оператор смены знака, применяемый к литералу `17`.

```python
million = 1000000
```

Единственное ограничение: у ненулевого числа не может быть **лишних
ведущих нулей** — `007` Python не примет:

```python
invalid_number = 007
# SyntaxError: leading zeros in decimal integer literals are not permitted;
# use an 0o prefix for octal integers
```

Десятичный литерал — самый частый способ записать целое число: он
совпадает с привычной записью чисел и подходит для любых «обычных»
величин — количеств, счетчиков, индексов, возрастов и так далее. К другим
системам счисления (двоичной, восьмеричной, шестнадцатеричной, см. ниже)
имеет смысл обращаться отдельно — например, когда число по смыслу
представляет собой битовую маску, флаги, цвет в формате RGB или адрес
памяти, и его структуру удобнее видеть не в десятичном виде.

### Литерал с подчеркиваниями-разделителями

Чтобы длинные числа было легче читать, группы цифр можно разделять с помощью
символа `_`. На само значение объекта это никак не влияет:

```python
million = 1_000_000
print(million)             # 1000000
print(million == 1000000)  # True
```

### Литералы в разных системах счисления

Помимо привычной десятичной системы, целые числа можно записывать сразу в
двоичной, восьмеричной или шестнадцатеричной системе с помощью
специальных префиксов:

| Система счисления | Префикс | Пример | Значение в десятичной |
|---|---|---|---|
| Двоичная | `0b` / `0B` | `0b1010` | 10 |
| Восьмеричная | `0o` / `0O` | `0o17` | 15 |
| Шестнадцатеричная | `0x` / `0X` | `0xFF` | 255 |

Такие литералы нужны для удобства решения некоторых задач. Двоичная запись напрямую
показывает набор битов (флаги, битовые маски: по `0b0000_0101` сразу
видно, какие биты включены). Шестнадцатеричная запись компактно и
предсказуемо представляет байты — поэтому в ней принято записывать цвета
(`0xFF0000` — красный), адреса памяти, коды символов, хеши. Восьмеричная
запись используется реже, в основном исторически — например, для
POSIX-прав доступа к файлам (`0o755`). Выбор системы счисления в таких
случаях — вопрос читаемости кода для человека, а не какое-то ограничение
самого языка.

```python
print(0b1010)   # 10
print(0o17)     # 15
print(0xFF)     # 255
```

**Важно**: как только литерал создан, это самый обычный объект `int` —
интерпретатору все равно, в какой системе счисления число было записано 
изначально:

```python
hex_value = 0xFF
decimal_value = 255
print(hex_value == decimal_value)  # True          -- это один и тот же объект-значение по смыслу
print(type(hex_value))             # <class 'int'> -- как и всегда
```

## 3. Создание целых чисел с помощью встроенного объекта `int()`

Встроенный объект `int()` создает целое число из другого объекта:

```python
int(3.9)        # 3      -- float -> int, дробная часть отбрасывается (не округление!)
int(-3.9)       # -3     -- отбрасывание происходит в сторону нуля
int(True)       # 1      -- bool -> int
int("42")       # 42     -- str -> int, строка должна быть похожа на целое число
int("  42  ")   # 42     -- пробелы по краям допустимы
int("42.0")     # ValueError -- а вот дробная строка -- уже нет
```

> **Важно.** `int(float)` **отбрасывает** дробную часть, а не округляет число с плавающей точкой.
> Для округления используйте встроенную функцию `round()` (см. отдельный конспект).

---

## 4. Настройка системы счисления в `int()`

Встроенный объект `int()` умеет создавать число не только из десятичной строки,
но и из строки в **произвольной системе счисления** от 2 до 36. Для выбора системы
счисления необходимо передать соответствующее значение в качестве значения параметра
`base`:

```python
int("1010", 2)  # 10  -- двоичная строка
int("17", 8)    # 15  -- восьмеричная строка
int("ff", 16)   # 255 -- шестнадцатеричная строка (регистр не важен)
int("z", 36)    # 35  -- максимальное основание -- 36 (0-9, затем a-z)
```

Строку также можно писать с префиксом (`0b`, `0o`, `0x`) — тогда основание
можно определить автоматически, передав `0` в качестве значения `base`:

```python
int("0b1010", 0)  # 10
int("0xff", 0)    # 255
```

Перевести `int` в строковое представление в другой
системе счисления помогают встроенные функции `bin()`, `oct()` и `hex()`:

```python
bin(10)   # '0b1010'
oct(15)   # '0o17'
hex(255)  # '0xff'
```

## 5. Отсутствие ограничения диапазона значений

В отличие от многих языков (C, Java), где целочисленный тип занимает
фиксированное количество бит (например, 32 или 64) и имеет четкие
границы значений, **диапазон значений `int` в Python не ограничен** — под число
любой величины интерпретатор выделяет ровно столько памяти, сколько нужно
для его хранения (bignum-арифметика). Переполнения при обычной арифметике
не возникает.

```python
huge_power = 2 ** 1000  # огромное число, никакого overflow

factorial_100 = 1

for n in range(1, 101):
    factorial_100 *= n

print(factorial_100)    # точное значение 100!, все 158 цифр
```

Единственное реальное ограничение — доступная память компьютера: чем
больше число, тем больше памяти требуется под его хранение и тем медленнее
выполняются операции с ним.

> **Историческая деталь.** Раньше в Python 2 существовали два разных типа —
> `int` (ограниченный, как в C) и `long` (неограниченный). В Python 3 они
> объединены в единственный тип `int` без ограничения диапазона.

---

## Вывод

- Создать `int` можно литералом или конструктором `int()` (из `float`,
  `bool`, `str`).
- `int(float)` **отбрасывает** дробную часть, а не округляет.
- Литералы можно записывать в десятичной, двоичной (`0b`), восьмеричной
  (`0o`) и шестнадцатеричной (`0x`) системах счисления, а также с
  разделителями `_` для читаемости.
- `int(строка, основание)` создает число из строки в произвольной системе
  счисления (2–36); `bin()`, `oct()`, `hex()` делают обратное преобразование.
- У `int` нет ограничения диапазона значений — числа могут быть сколь
  угодно большими, ограничение только одно — объем доступной памяти.
