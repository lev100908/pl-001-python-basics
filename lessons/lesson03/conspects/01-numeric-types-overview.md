# Числовые типы данных: обзор

> **Главная мысль.** В Python есть четыре встроенных числовых типа данных:
> `bool`, `int`, `float` и `complex`. Они образуют цепочку «расширений»
> `bool -> int -> float -> complex`: каждый следующий тип умеет представлять
> более широкий класс чисел, чем предыдущий, и Python сам приводит к нему
> значения при смешанных операциях.

---

## 1. Четыре числовых типа

Числовые типы данных нужны, чтобы представлять в программе количественные и
логические данные — счетчики, суммы, координаты, вероятности, ответы
«да/нет» и так далее — и выполнять над ними различные операции. Числовых типов
данных несколько, потому что для разных задач требуется разный функционал.

| Тип | Что представляет | Пример |
|---|---|---|
| `bool` | логическое значение (по сути — 0 или 1) | `True`, `False` |
| `int` | целое число, без ограничения диапазона | `42`, `-7`, `10**100` |
| `float` | число с плавающей точкой (приближенное вещественное) | `3.14`, `-0.5` |
| `complex` | комплексное число (действительная + мнимая часть) | `2 + 3j` |

Все четыре — **встроенные (built-in)** типы, отдельно объявлять их не нужно:
объект нужного типа создается сразу, как только в коде появляется
соответствующий литерал.

---

## 2. Цепочка `bool -> int -> float -> complex`

Числовые типы в Python выстроены в иерархию: каждый тип справа — это
**расширение** типа слева, способное представить все его значения и еще
больше.

- **`bool -> int`.** `bool` — подтип `int`: `True` и `False` фактически ведут
  себя как `1` и `0` и участвуют в арифметике наравне с обычными целыми
  числами (подробнее — в конспекте про `bool`).
- **`int -> float`.** Любое целое число можно представить как число с
  плавающей точкой (`5` -> `5.0`), но не наоборот: `float` может хранить
  дробную часть, которой у `int` не существует.
- **`float -> complex`.** Любое вещественное число можно представить как
  комплексное с нулевой мнимой частью (`5.0` -> `5.0 + 0j`), но `complex`
  умеет хранить еще и мнимую часть, которой у `float` нет.

```python
int(True)      # 1     -- bool -> int
float(5)       # 5.0   -- int -> float
complex(5.0)   # (5+0j) -- float -> complex
```

Эта цепочка важна на практике: когда в одной операции встречаются значения
разных числовых типов, Python неявно приводит более "узкий" тип к более
"широкому" (см. конспект про арифметические операции), а не наоборот.

---

## 3. Оговорка про `complex`

`complex` — тип для комплексных чисел (действительная и мнимая часть,
`a + bj`), востребованный в первую очередь в узких инженерных и научных
задачах (обработка сигналов, электротехника, некоторые численные методы).
В большинстве прикладных Python-проектов (веб, автоматизация, анализ
данных общего назначения) этот тип практически не используется.

По этой причине **в рамках курса `complex` подробно не рассматривается** —
дальше мы разберем `int`, `float` и `bool`, а также операции над ними.

---

## Вывод

- В Python четыре встроенных числовых типа: `bool`, `int`, `float`,
  `complex`.
- Они образуют цепочку расширений `bool -> int -> float -> complex`: каждый
  следующий тип может представить все значения предыдущего и что-то сверх
  того.
- `complex` в курсе не рассматривается из-за узкой области применения на
  практике.
