# Встроенные функции для чисел: `abs()` и `round()`

> **Главная мысль.** `abs()` возвращает модуль (абсолютное значение) числа,
> `round()` округляет число до заданного количества знаков после запятой.
> У обеих функций есть детали поведения, которые стоит знать заранее:
> `round()` округляет не «как в школе», а к ближайшему **четному** числу
> при равном удалении от двух соседних значений.

---

## 1. `abs()` — модуль числа

`abs(x)` возвращает абсолютное значение числа — само число, если оно
неотрицательно, и число с обратным знаком, если оно отрицательно.

```python
abs(5)       # 5
abs(-5)      # 5
abs(-3.14)   # 3.14
abs(0)       # 0
abs(True)    # 1  -- bool -- тоже число
```

Тип результата совпадает с типом аргумента (кроме `bool`, который всегда
становится `int`, как и в любой другой арифметике):

```python
type(abs(-5))    # <class 'int'>
type(abs(-5.0))  # <class 'float'>
type(abs(True))  # <class 'int'>
```

Типичное применение — вычисление расстояния между числами (модуль
разности) или проверка, насколько число близко к нулю:

```python
first_number, second_number = 7, 2
distance = abs(first_number - second_number)     # 5 -- "расстояние" между числами на числовой прямой
```

---

## 2. `round()` — округление

`round(number)` округляет число до ближайшего целого и возвращает `int`:

```python
round(3.2)   # 3
round(3.8)   # 4
round(-3.2)  # -3
round(-3.8)  # -4
```

`round(number, ndigits)` округляет до `ndigits` знаков после запятой и
возвращает число **того же типа**, что и исходное (`float`, если на входе
был `float`):

```python
round(3.14159, 2)      # 3.14
round(3.14159, 0)      # 3.0  -- обратите внимание: float, а не int, т.к. передан ndigits
round(1234.5678, -2)   # 1200.0 -- отрицательный ndigits: округление до сотен
```

---

## 3. Особенность округления: округление к четному (banker's rounding)

Многие привыкли, что `0.5` всегда округляется вверх.
В Python `round()` работает **иначе**: при значении ровно посередине
между двумя соседними числами результат округляется в сторону
**ближайшего четного** числа. Это называется «банковским округлением»
(banker's rounding, round half to even) — оно используется, чтобы не
накапливать систематическое смещение результата при округлении большого
количества значений в одну сторону.

```python
round(0.5)  # 0  -- не 1! 0 -- четное, оно ближе "по четности"
round(1.5)  # 2  -- 2 -- четное
round(2.5)  # 2  -- не 3! 2 -- четное
round(3.5)  # 4  -- 4 -- четное
```

> **Осторожно.** Из-за погрешностей представления `float` (см. конспект
> про арифметические операции) на конкретных дробных числах результат
> округления может выглядеть неожиданным — например, `round(2.675, 2)`
> дает `2.67`, а не `2.68`, потому что `2.675` физически не хранится как
> точное значение `2.675`, а как чуть меньшее число. Если для задачи
> критична десятичная точность (например, денежные расчеты), вместо
> `float` и `round()` стоит использовать модуль `decimal`.

---

## Вывод

- `abs(x)` — модуль числа, тип результата совпадает с типом аргумента
  (`bool` приводится к `int`, как и в любой арифметике).
- `round(x)` округляет до целого и возвращает `int`; `round(x, ndigits)`
  округляет до `ndigits` знаков и возвращает число того же типа, что и `x`.
- `round()` округляет половинные значения (`0.5`, `2.5`, …) к ближайшему
  **четному** числу (banker's rounding), а не всегда «вверх» — это частая
  неожиданность для тех, кто не знаком с этим поведением.
- Для точных десятичных вычислений (например, денег) `float` и `round()`
  не подходят — для этого есть модуль `decimal`.
