# Тип данных с плавающей точкой `float`

> **Главная мысль.** `float` — тип для чисел с плавающей точкой (приближенных
> вещественных чисел). Создать значение можно литералом или конструктором
> `float()`. В отличие от `int`, у `float` **есть** ограничение диапазона значений и
> точности, а также три специальных значения: `+inf`, `-inf` и `nan`.

---

## 1. Литералы

Самый простой способ получить значение `float` — записать его прямо в
коде в виде литерала: числа с точкой между целой и дробной частью,
записанные десятичными цифрами. Есть и другие формы записи литерала —
о них пойдет речь ниже.

```python
positive_number = 3.14
negative_number = -0.5
whole_number = 2.0
```

---

## 2. Виды литералов

Литерал `float` можно записать несколькими способами:

```python
1.5      # обычная запись с целой и дробной частью
.5       # 0.5    -- допустимо опустить целую часть
5.       # 5.0    -- допустимо опустить дробную часть
1_000.5  # 1000.5 -- разделитель _ работает и здесь
```

Также поддерживается **экспоненциальная (научная) запись** — `e`/`E` перед
показателем степени десятки. Число вида `mantissa`e`exponent` означает
`mantissa * 10 ** exponent` — так удобно записывать очень большие или
очень маленькие числа, не выписывая вручную все нули:

```python
1e3    # 1000.0 -- 1 * 10**3
1.5e2  # 150.0  -- 1.5 * 10**2
2e-3   # 0.002  -- 2 * 10**-3
```

В отличие от `int`, у `float` **нет** отдельных литералов для двоичной,
восьмеричной или шестнадцатеричной систем счисления — только десятичная
запись (целая часть, дробная часть, экспонента).

> **Внутреннее устройство.** `float` в Python — это число двойной точности
> по стандарту IEEE 754 (64 бита: знак, экспонента, мантисса) — тот же
> формат, что используется в большинстве других языков программирования.

---

## 3. Встроенный объект `float`

Помимо литерала, значение `float` можно получить с помощью встроенного
объекта (конструктора) `float()` — он преобразует в `float` значения
других типов:

```python
float(5)          # 5.0        -- int -> float
float(True)       # 1.0        -- bool -> float
float("3.14")     # 3.14       -- str -> float
float("  3.14 ")  # 3.14       -- пробелы по краям допустимы
float("abc")      # ValueError
```

---

## 4. Ограничение диапазона и точности

В отличие от `int`, у `float` **есть** ограничения — и по диапазону
значений, и по точности представления:

```python
import sys

print(sys.float_info.max)      # ~1.7976931348623157e+308 -- максимальное конечное значение
print(sys.float_info.epsilon)  # ~2.22e-16 -- минимальная разница между различимыми числами
```

Если результат вычисления превышает максимально возможное значение —
получается специальное значение `inf` (см. ниже), а не ошибка и не
"следующее" число, как это происходит с `int`:

```python
huge = 10.0 ** 308
print(huge)          # 1e+308      -- еще влезает
print(huge * 10)     # inf         -- переполнение float, а не исключение
```

Кроме того, многие дробные числа **не могут быть представлены точно** в
двоичной системе (так же, как 1/3 не представить точно в десятичной) —
отсюда возникают погрешности вычислений, которые подробно разбираются в
конспекте про арифметические операции.

---

## 5. Специальные значения: `+inf`, `-inf`, `nan`

Помимо обычных чисел, `float` умеет представлять три особых значения.

### `+inf` и `-inf` — положительная и отрицательная бесконечность

Обозначают результат, который больше (или меньше) любого представимого
числа — например, при переполнении или при делении числа на очень
маленькое значение.

```python
float("inf")   # inf
float("-inf")  # -inf

import math
import sys

math.inf    # inf  -- то же самое значение, доступно как константа
-math.inf   # -inf

huge = sys.float_info.max
huge * 2    # inf  -- переполнение при умножении
-huge * 2   # -inf
```

> **Осторожно.** Не все операции при переполнении ведут себя одинаково:
> `*` и `+` возвращают `inf` (как показано выше), а вот `**` в этой
> ситуации **бросает исключение** `OverflowError`, а не возвращает `inf`:
>
> ```python
> 10.0 ** 400  # OverflowError: (34, 'Numerical result out of range')
> ```

Назначение: `inf` используется как «условно бесконечно большое» число —
например, как стартовое значение при поиске минимума («любое число меньше
этого»), либо как признак переполнения при вычислениях.

```python
best = math.inf

for value in [5, 2, 8, 1, 9]:
    if value < best:
        best = value

print(best)   # 1
```

> **Осторожно.** Деление `float` на `0.0` в Python **не** дает `inf` —
> оно, как и деление `int` на `0`, вызывает исключение `ZeroDivisionError`.
> Получить `inf` можно только через литерал/конструктор (`float("inf")`,
> `math.inf`) или как результат переполнения при вычислениях.

### `nan` — "не число" (Not a Number)

Обозначает результат неопределенной или некорректной операции с
плавающей точкой (а также используется как маркер отсутствующих/некорректных данных).

```python
float("nan")  # nan

import math
math.nan      # nan -- то же самое, доступно как константа
```

`nan` получается не только через литерал/конструктор, но и как результат
некоторых операций с `inf` — таких, у которых нет однозначного
математического результата:

```python
math.inf - math.inf    # nan -- "бесконечность минус бесконечность"
math.inf * 0           # nan -- "бесконечность, умноженная на ноль"
math.inf / math.inf    # nan -- отношение двух бесконечностей
```

Главная особенность `nan` — он **не равен даже самому себе**:

```python
not_a_number = float("nan")
print(not_a_number == not_a_number)  # False -- по стандарту IEEE 754 так и должно быть
print(not_a_number != not_a_number)  # True

math.isnan(not_a_number)          # True -- правильный способ проверить именно на nan
```

Назначение: `nan` используется как маркер «значение отсутствует» или
«результат не определен» — например, в таблицах данных (pandas), где
`nan` обозначает пропуск в данных, или как признак некорректного
промежуточного результата вычислений, который нужно отследить.

---

## Вывод

- Создать `float` можно литералом (`3.14`, `.5`, `5.`, `1e3`) или
  конструктором `float()` (из `int`, `bool`, `str`).
- Литералы `float` — только в десятичной системе, но поддерживают
  экспоненциальную запись (`e`/`E`) и разделители `_`.
- В отличие от `int`, у `float` **есть** ограничение диапазона (IEEE 754,
  двойная точность) и ограниченная точность представления дробных чисел.
- `+inf`/`-inf` — специальные значения для бесконечности (переполнение,
  «условно бесконечно большое» число); `nan` — «не число», маркер
  неопределенного результата или пропуска в данных. Для проверки на `nan`
  используют `math.isnan()`, а не `==`.
