# Форматирование чисел

> **Главная мысль.** Спецификатор формата (то, что стоит после `:` в `{}`)
> превращает число в строку нужного вида: с заданным
> **количеством знаков после запятой** (`.2f`), в виде **процентов** (`.1%`),
> с **разделителями разрядов** (`,` или `_`) и
> нулями слева. Результат форматирования — всегда **строка**, а не число.

---

## 1. Тип и точность

### Числа с плавающей точкой: `f`, `e`, `g`

**Точность** — число после точки (`.2`) — для чисел с плавающей точкой
задает количество знаков после запятой при типе `f` (fixed-point). Значение
**округляется**:

```python
pi = 3.14159265

print(f"{pi:.0f}")  # 3
print(f"{pi:.2f}")  # 3.14
print(f"{pi:.4f}")  # 3.1416
print(f"{pi:f}")    # 3.141593 -- по умолчанию 6 знаков
```

Целые числа тоже можно форматировать как `f` — они будут приведены к
числам с плавающей точкой:

```python
print(f"{5:.2f}")  # 5.00
```

Другие типы для вещественных чисел: `e` — научная запись (степень
десяти), `g` — «общий» формат, где `точность` означает **количество
значащих цифр**. «Общий» он потому, что сам выбирает вид записи: если число
помещается в заданное количество цифр, оно выводится обычным образом
(без лишних нулей в конце), а если нет — в научной записи.

```python
big_number = 123456.789

print(f"{big_number:.2e}")  # 1.23e+05
print(f"{big_number:.3g}")  # 1.23e+05 -- 6 цифр в целой части не помещаются в 3
print(f"{3.14159:.3g}")     # 3.14
print(f"{0.5:.3g}")         # 0.5      -- хвостовые нули не добавляются
```

### Округление при форматировании

Форматирование округляет по тем же правилам, что и функция `round()` (см.
конспект про `abs()` и `round()`): при равноудаленном значении — до
ближайшего **четного** (banker's rounding), а двоичное представление
`float` приводит к ожидаемым «странностям»:

```python
print(f"{0.125:.2f}")  # 0.12 -- ровно посередине, округление к четному
print(f"{0.375:.2f}")  # 0.38 -- ровно посередине, округление к четному
print(f"{2.675:.2f}")  # 2.67 -- в двоичном виде число чуть меньше 2.675
```

Форматирование и `round()` — разные вещи: `round()` возвращает **число**,
а форматирование — **строку** (с сохранением «хвостовых» нулей):

```python
print(round(2.5001, 2))  # 2.5   -- число: хвостовой нуль не виден
print(f"{2.5001:.2f}")   # 2.50  -- строка: два знака после запятой
```

### Целые числа: `d`, `b`, `o`, `x`, `X`

Целые числа можно показать в разных системах счисления. Символ `#`
добавляет префикс, обозначающий систему:

```python
number = 255

print(f"{number:d}")   # 255
print(f"{number:b}")   # 11111111
print(f"{number:o}")   # 377
print(f"{number:x}")   # ff
print(f"{number:X}")   # FF
print(f"{number:#x}")  # 0xff
print(f"{number:#b}")  # 0b11111111
```

### Точность для строк

Для строк точность означает **максимальное число символов** — лишние
обрезаются:

```python
print(f"{'abcdef':.3}")  # abc
```

## 2. Проценты: `%`

Тип `%` **умножает число на 100** и добавляет знак процента. Точность
задает число знаков после запятой уже в процентах:

```python
share = 0.256

print(f"{share:%}")    # 25.600000%
print(f"{share:.1%}")  # 25.6%
print(f"{share:.0%}")  # 26%
print(f"{1:.0%}")      # 100%
```

Обратите внимание: в значение нужно передавать **долю** (`0.256`), а не
готовое число процентов (`25.6`) — иначе получится `2560.0%`.

## 3. Разделители разрядов и их настройка

Для длинных чисел удобны разделители тысяч. В спецификаторе формата для
этого есть два символа:

- `,` — запятая как разделитель тысяч;
- `_` — нижнее подчеркивание (такая же запись допустима в числовых
  литералах: `1_000_000`).

```python
population = 1234567

print(f"{population:,}")      # 1,234,567
print(f"{population:_}")      # 1_234_567
print(f"{1234567.891:,.2f}")  # 1,234,567.89
```

---

## 4. Ширина и нули слева

Число в спецификаторе — **минимальная ширина** поля: если число короче,
оно дополняется пробелами (по умолчанию числа выравниваются по правому
краю). Если перед шириной стоит `0`, дополнение происходит **нулями**
(у отрицательных чисел — после знака):

```python
print(f"[{42:6d}]")          # [    42]
print(f"[{42:06d}]")         # [000042]
print(f"[{-42:06d}]")        # [-00042]
print(f"[{3.14159:08.3f}]")  # [0003.142]
```

Типичное применение — идентификаторы и время фиксированной ширины:

```python
hours = 7
minutes = 5

print(f"{hours:02d}:{minutes:02d}")  # 07:05
```

---

## Вывод

- `.Nf` — фиксированное число знаков после запятой; `e` — научная запись;
  `g` — число значащих цифр. Округление — по правилам `round()`.
- `%` умножает число на 100 и добавляет знак `%`: `f"{0.256:.1%}"` →
  `25.6%`.
- `,` и `_` — единственные встроенные разделители разрядов.
- `0` перед шириной дополняет число нулями слева (`{5:02d}` → `05`).
- Результат форматирования — **строка**, в отличие от `round()`, который
  возвращает число.
