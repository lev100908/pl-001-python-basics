# Разбиение и объединение строк: `split()` и `join()`

> **Главная мысль.** Метод `split()` **разбивает** строку на **список**
> подстрок по разделителю, а `join()` выполняет обратное действие — **склеивает**
> элементы итерируемого объекта в одну строку, подставляя между ними строку-разделитель.
> Эта пара — основной инструмент разбора текстовых данных (строки
> CSV, команды, слова предложения) и сборки результата. Метод `join()`
> вызывается **у разделителя**, а не у списка, и принимает только строки.

---

## 1. Метод `split()`

### Разбиение по пробельным символам

Вызванный **без аргументов**, `split()` разбивает строку по **любым
последовательностям пробельных символов** (пробелы, табуляции, переводы строк)
и **отбрасывает пустые элементы**. Поэтому лишние пробелы по краям и
повторяющиеся пробелы внутри на результат не влияют:

```python
sentence = "  the   quick\tbrown\nfox  "

print(sentence.split())  # ['the', 'quick', 'brown', 'fox']
```

Результат всегда **список строк** — это основной способ разделить текст на
слова:

```python
words = "to be or not to be".split()

print(words)       # ['to', 'be', 'or', 'not', 'to', 'be']
print(len(words))  # 6
```

### Разбиение по заданному разделителю

Если передать строку `sep`, разбиение выполняется **строго по ней**. В
этом режиме пустые элементы **сохраняются**: два подряд идущих
разделителя дадут пустую строку между ними. Разделитель может состоять
из нескольких символов:

```python
print("a,b,c".split(","))       # ['a', 'b', 'c']
print("a,,b".split(","))        # ['a', '', 'b'] -- пустой элемент сохранен
print("a--b--c".split("--"))    # ['a', 'b', 'c']
print("2024-05-17".split("-"))  # ['2024', '05', '17']
```

Разделитель — **не набор символов**, а точная подстрока (в отличие от
аргумента `strip()`). Пустую строку в качестве разделителя использовать
нельзя:

```python
print("abc".split(""))
# ValueError: empty separator
```

Разбиение пустой строки отличается в двух режимах:

```python
print("".split())     # []   -- без аргументов: пустой список
print("".split(","))  # ['']  -- с разделителем: список из одной пустой строки
```

### Ограничение числа разбиений: `maxsplit`

Второй параметр `maxsplit` задает максимальное количество разбиений
(тогда в результате будет не более `maxsplit + 1` элементов):

```python
line = "key=value=extra"

print(line.split("=", 1))  # ['key', 'value=extra']
print(line.split("=", 2))  # ['key', 'value', 'extra']
```

Это позволяет, например, отделить первое слово или разобрать пару «ключ —
значение», в которой значение само может содержать разделитель.

`rsplit()` работает так же, как `split()`, но считает разбиения **справа**:

```python
print("a.b.c.d".split(".", 1))   # ['a', 'b.c.d']
print("a.b.c.d".rsplit(".", 1))  # ['a.b.c', 'd']
```

### Частые приемы

Разбор строки в числа — каждый элемент превращают отдельно:

```python
numbers = [int(part) for part in "10 20 30".split()]

print(numbers)       # [10, 20, 30]
print(sum(numbers))  # 60
```

Если число частей известно заранее, результат удобно **распаковать**:

```python
year, month, day = "2024-05-17".split("-")

print(year, month, day)  # 2024 05 17

key, value = "color=red".split("=")

print(key, value)  # color red
```

## 2. Метод `join()`

### Как устроен `join()`

`separator.join(iterable)` склеивает все элементы итерируемого объекта в
одну строку, вставляя `separator` **между** элементами (но не в начало и
не в конец):

```python
words = ["to", "be", "or", "not", "to", "be"]

print(" ".join(words))   # to be or not to be
print(", ".join(words))  # to, be, or, not, to, be
print("".join(words))    # tobeornottobe
print("-".join(["a"]))   # a -- разделитель не нужен, элемент один
print(" ".join([]))      # (пустая строка)
```

Метод вызывается **у строки-разделителя**, а не у списка. Это не прихоть: так
метод `join()` существует один раз — у `str` — и работает с **любым**
итерируемым объектом (список, кортеж, множество, генератор, другая строка),
вместо того чтобы дублироваться во всех коллекциях:

```python
print("-".join(("a", "b", "c")))  # a-b-c -- кортеж
print("-".join("abc"))            # a-b-c -- строка тоже итерируема
```

### Элементы должны быть строками

`join()` склеивает **только строки**. Если среди элементов окажется
число или другой объект, возникнет `TypeError` — нужно предварительно
преобразовать значения с помощью `str()`:

```python
numbers = [1, 2, 3]

print(", ".join(numbers))
# TypeError: sequence item 0: expected str instance, int found

print(", ".join([str(number) for number in numbers]))  # 1, 2, 3
```

### Сборка строки в цикле: `join()` вместо `+=`

В конспекте про строки как последовательности отмечалось, что `+=` в цикле
создает новую строку на каждом шаге. Правильный способ собрать результат из
многих частей — накопить их **в списке** и один раз объединить:

```python
parts = []

for number in range(1, 6):
    parts.append(str(number))

print(",".join(parts))  # 1,2,3,4,5
```

---

## Вывод

- `split()` без аргументов делит по пробельным символам и **отбрасывает
  пустые** элементы; `split(sep)` делит строго по `sep` и **сохраняет
  пустые** элементы. Результат — **список строк**.
- `maxsplit` ограничивает число разбиений; `rsplit()` разбивает справа.
- `separator.join(iterable)` склеивает **строки** в одну, вставляя
  разделитель между элементами; работает с любым итерируемым объектом.
- Нестроковые элементы нужно предварительно привести к строке (`str()`).
- Для сборки большой строки из частей накапливайте их в списке и вызывайте
  `join()` один раз.
