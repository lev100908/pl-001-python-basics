# Строки: обзор и характеристики

> **Главная мысль.** `str` — встроенный тип данных для хранения текста.
> Строка — это **последовательность** символов Unicode, причем
> отдельного типа «символ» в Python нет: каждый элемент строки — это тоже
> строка, но длиной в один символ. Строка **гомогенна** (все элементы одного
> типа), **ограничена** (длину можно узнать через `len()`), **упорядочена**
> (у каждого символа есть индекс), **итерируема** (символы можно обходить
> в цикле) и **неизменяема**.

---

## 1. Строка — последовательность символов

Все типы данных, которые мы разбирали ранее, делятся на **скалярные**
(`int`, `float`, `bool`) и **составные** (`list`, `tuple`). `str` занимает
промежуточное положение: объект строки хранит один цельный текст, но при
этом этот текст — **упорядоченный набор символов**, к которым можно
обращаться по отдельности. Поэтому строка относится к **последовательностям**
(sequences), как и список с кортежем из прошлого занятия.

```python
greeting = "hello"

print(greeting)        # hello
print(type(greeting))  # <class 'str'>
```

---

## 2. Характеристики строки

### Гомогенность

В отличие от списка, который **гетерогенен**, строка **гомогенна**: все ее
элементы имеют один и тот же тип. В Python нет отдельного типа для одного
символа (как `char` в C или Java) — элемент строки сам является строкой,
длина которой равна `1`:

```python
word = "python"
first_char = word[0]

print(first_char)        # p
print(type(first_char))  # <class 'str'>
print(len(first_char))   # 1
```

Из-за этого в строку нельзя «положить» число или другой объект — она
может состоять только из символов:

```python
print("abc" + "1")  # abc1
print("abc" + 1)
# TypeError: can only concatenate str (not "int") to str
```

### Ограниченность

Строка **ограничена**: в любой момент времени она содержит конкретное,
конечное количество символов, которое можно узнать с помощью встроенной
функции `len()`. Пустая строка (`""`) — тоже строка, ее длина равна нулю:

```python
print(len("python"))        # 6
print(len("hello, world"))  # 12 -- пробел и запятая тоже считаются символами
print(len(""))              # 0
```

### Упорядоченность

Строка **упорядочена**: символы хранятся в том порядке, в котором они
записаны, и у каждого символа есть свой **индекс**. Индексация, как и у
списка, начинается с `0` и поддерживает отрицательные индексы:

```python
word = "python"

print(word[0])   # p -- первый символ
print(word[2])   # t
print(word[-1])  # n -- последний символ
```

Порядок имеет значение: строки `"abc"` и `"cba"` состоят из одних и тех же
символов, но это **разные** строки:

```python
print("abc" == "cba")  # False
```

### Итерируемость

Строка **итерируема** — ее символы можно обойти по одному, например, в
цикле `for`, в том порядке, в котором они расположены в строке:

```python
for char in "abc":
    print(char)
```

Вывод:
```
a
b
c
```

### Неизменяемость

Строка **неизменяема (immutable)**: после создания нельзя заменить,
удалить или добавить символ — присваивание по индексу приводит к
`TypeError`:

```python
word = "python"

word[0] = "P"
# TypeError: 'str' object does not support item assignment
```

Все методы строк, которые «изменяют» текст (`upper()`, `replace()`,
`strip()` и другие), на самом деле **не меняют исходную строку, а
возвращают новую**. Чтобы сохранить результат, его нужно присвоить имени:

```python
word = "python"
upper_word = word.upper()

print(word)        # python -- исходная строка не изменилась
print(upper_word)  # PYTHON -- это новая строка
```

Присваивание `word = word.upper()` тоже не изменяет объект: оно лишь
**перепривязывает** имя к новому объекту (подробнее о привязке имен — в
конспекте про объекты из занятия 2):

```python
word = "python"
identity_before = id(word)

word = word.upper()

print(word)                         # PYTHON
print(id(word) == identity_before)  # False -- имя указывает на другой объект
```

Неизменяемость дает строкам важное преимущество: строку безопасно
передавать в функции и хранить в разных местах — никто не сможет
«незаметно» изменить ее содержимое.

## 3. Для чего используются строки

Строки — один из самых часто встречающихся типов данных, потому что
почти все, что человек вводит в программу и получает из нее, — это текст:

- ввод пользователя (`input()` всегда возвращает строку) и вывод
  сообщений (`print()`);
- имена, адреса, названия, пароли и другие текстовые поля;
- пути к файлам и содержимое текстовых файлов;
- форматы обмена данными: JSON, CSV, HTML, логи — все это текст;
- построение и разбор команд, запросов и сообщений.

---

## Вывод

- `str` — встроенный тип для хранения текста; строка — **последовательность
  символов Unicode**.
- Отдельного типа для символа в Python нет: элемент строки — это строка
  длиной `1`.
- Строка **гомогенна** (все элементы — строки), **ограничена** (длина
  через `len()`), **упорядочена** (индексы с `0` и отрицательные), **итерируема**
  (обход в цикле `for`) и **неизменяема**.
- Методы строк не меняют исходный объект, а **возвращают новую строку** —
  результат нужно сохранять.
