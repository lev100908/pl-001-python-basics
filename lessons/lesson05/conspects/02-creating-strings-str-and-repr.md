# Создание строк: `str()` и `repr()`

> **Главная мысль.** Строку можно получить из значения любого типа с
> помощью встроенного объекта `str` — он возвращает **читаемое для
> человека** представление объекта. Встроенная функция `repr()` тоже
> возвращает строку, но на этот раз **однозначное представление для разработчика**: по
> нему видно, какого типа объект и какие именно символы он содержит. `print()`
> использует `str()`, а интерактивный режим (REPL) показывает результат
> выражения через `repr()`.

---

## 1. Встроенный объект `str`

`str` — это объект-класс (тип данных `str`). Как и `int` или `float`, его
можно **вызвать**, чтобы создать новый объект этого типа — строку. Без
аргументов вызов возвращает пустую строку, а с аргументом — строковое
представление переданного объекта:

```python
print(repr(str()))  # ''
print(str(42))    # 42
print(str(3.14))  # 3.14
print(str(True))  # True
print(str(None))  # None
```

На вход `str` принимает **любой** объект — в том числе составной. Для списка
результирующая строка будет содержать запись списка целиком, в том числе скобки и запятые:

```python
print(str([1, 2, 3]))  # [1, 2, 3]
print(str((1, "a")))   # (1, 'a')

print(type(str([1, 2, 3])))  # <class 'str'> -- это одна строка, а не список
```

Самое частое применение `str()` — собрать из значений разных типов
единый текст. Строки нельзя «сложить» с числами напрямую, поэтому число
нужно сначала явно превратить в строку:

```python
age = 25

print("Age: " + str(age))  # Age: 25
print("Age: " + age)
# TypeError: can only concatenate str (not "int") to str
```

Обратное преобразование — из строки в число — делают уже знакомые объекты
`int` и `float`. Если строка не похожа на число, возбуждается `ValueError`:

```python
print(int("42") + 1)     # 43
print(float("3.5") * 2)  # 7.0

print(int("forty two"))
# ValueError: invalid literal for int() with base 10: 'forty two'
```

## 2. Встроенная функция `repr()`

`repr()` тоже принимает любой объект на вход и возвращает строку, но с другой
целью. Если `str()` отвечает на вопрос «**как показать значение
человеку**», то `repr()` — «**как однозначно описать объект
разработчику**». Там, где это возможно, `repr()` возвращает строку, которая
выглядит как корректный Python-код для создания такого же объекта.

Главное отличие видно на строках: `repr()` добавляет кавычки, поэтому по
результату можно отличить строку от других типов данных:

```python
print(42)    # 42
print("42")  # 42 -- print() выводит текст как есть, на глаз не отличить от числа

print(repr(42))    # 42
print(repr("42"))  # '42' -- кавычки сразу показывают, что это строка
```

Вторая важная особенность: `repr()` **показывает служебные символы** в
экранированном виде (подробно про них — в следующих конспектах). Поэтому
`repr()` незаменим при отладке — например, чтобы заметить лишние пробелы и
переводы строк, которые не видны при обычном выводе:

```python
text = "hello \n"

print(text)        # hello (и пустая строка после -- перевод строки не виден)
print(repr(text))  # 'hello \n'
```

Если внутри строки есть одинарная кавычка, а двойной нет, `repr()`
выбирает для оформления двойные кавычки — чтобы не экранировать:

```python
print(repr("it's"))  # "it's"
print(repr("abc"))   # 'abc'
```

### `str()` и `repr()`: в чем разница на практике

|  | `str(obj)` | `repr(obj)` |
|---|---|---|
| Для кого | для пользователя (читаемость) | для разработчика (однозначность) |
| Кавычки у строк | нет | есть |
| Служебные символы (`\n`, `\t`) | выводятся «как есть» (переводят строку, табулируют) | показываются в экранированном виде |
| Кто использует | `print()` | REPL, отладка, содержимое списков |

Последняя строка таблицы — частый источник вопросов: **элементы внутри
списка или кортежа всегда выводятся через `repr()`**, даже когда сам
контейнер печатают через `print()`:

```python
words = ["hello", "world"]

print(words)     # ['hello', 'world'] -- у элементов есть кавычки
print(words[0])  # hello              -- а у отдельной строки их нет
```

Интерактивный режим работает так же: результат выражения в REPL
показывается через `repr()`, а `print()` — через `str()`:

```
>>> "hello"
'hello'
>>> print("hello")
hello
```

Для чисел `str()` и `repr()` совпадают, поэтому в REPL разницы заметно не
будет — она проявляется на строках и объектах, которые содержат строки.

---

## Вывод

- Встроенный объект `str` создает строку из значения любого типа:
  `str()` — пустая строка, `str(42)` — `'42'`.
- Строку и число нельзя сложить напрямую — число нужно привести к
  строке с помощью `str()`; обратно строку в число превращают `int()` и
  `float()`.
- `str()` дает представление, **удобное для человека**, `repr()` —
  **однозначное, для разработчика**: с кавычками у строк и с видимыми
  служебными символами.
- `print()` использует `str()`; REPL и вывод содержимого
  списков и кортежей — `repr()`.
