# Логические операции над строками

> **Главная мысль.** Строки можно сравнивать на равенство (`==`, `!=`) —
> сравнение **посимвольное и регистрозависимое** — и по порядку (`<`, `>`,
> `<=`, `>=`) — **лексикографически**, то есть по кодам символов Unicode.
> Поэтому порядок строк не совпадает ни с «человеческим» алфавитным порядком, ни с
> порядком чисел (`"10" < "9"`). Строка с точки зрения проверки истинности
> ложна, только если она пустая.

---

## 1. Сравнение на равенство: `==` и `!=`

Две строки равны, если они **одинаковой длины и состоят из одних и тех же
символов в одном и том же порядке**. Сравнение учитывает регистр, пробелы и
служебные символы:

```python
print("python" == "python")   # True
print("python" == "Python")   # False -- регистр важен
print("python" == "python ")  # False -- пробел в конце тоже символ
print("abc" != "abd")         # True
```

Строка **никогда не равна** объекту другого типа, даже если «выглядит» как
число — неявного приведения типов, как между `int` и `float`, здесь нет:

```python
print("1" == 1)       # False
print("1" == str(1))  # True
```

### Не используйте `is` для сравнения строк

Оператор `is` проверяет **идентичность** объектов (один и тот же объект ли
это), а не равенство значений. Две равные строки не обязаны быть одним
объектом, поэтому для сравнения текста всегда нужно использовать `==`:

```python
first = "".join(["he", "llo"])
second = "hello"

print(first == second)  # True  -- значения равны
print(first is second)  # False -- это два разных объекта (в CPython)
```

Результат `is` для строк зависит от внутренних оптимизаций интерпретатора
(например, повторного использования одинаковых строк) и не гарантирован
языком — полагаться на него нельзя.

---

## 2. Отношения порядка: `<`, `>`, `<=`, `>=`

Строки можно сравнивать и по порядку. Сравнение **лексикографическое**
(как слова в словаре), но вместо алфавита используется порядок **кодов
символов Unicode** (код символа можно получить с помощью функции `ord()` —
см. следующий конспект). Алгоритм таков:

1. строки сравниваются **посимвольно слева направо**, пока не найдется первая
   пара различающихся символов;
2. меньшей считается та строка, у которой в этой позиции **код символа
   меньше**;
3. если одна строка является началом (префиксом) другой, **короче — меньше**;
   пустая строка меньше любой непустой.

```python
print("apple" < "banana")   # True  -- 'a' (97) < 'b' (98)
print("apple" < "apricot")  # True  -- первые символы равны, 'p' (112) < 'r' (114)
print("app" < "apple")      # True  -- "app" -- префикс, а значит короче
print("" < "a")             # True
print("abc" <= "abc")       # True
```

### Следствия: порядок кодов — не порядок «по-человечески»

Поскольку сравниваются коды символов, получаются неочевидные для новичка
результаты:

- **Заглавные буквы «меньше» строчных** — код `"Z"` (90) меньше кода
  `"a"` (97):

  ```python
  print("Zebra" < "apple")  # True
  print("Apple" < "apple")  # True
  ```

- **Цифры сравниваются как символы, а не как числа** — `"1"` в `"10"`
  сравнивается с `"9"`, и побеждает 9:

  ```python
  print("10" < "9")  # True -- сравнивается '1' (49) и '9' (57)
  print(10 < 9)      # False
  ```

- **Порядок кодов не всегда совпадает с алфавитом языка**. Например, в
  таблице Unicode русская буква «ё» (код 1105) расположена **после** «я»
  (код 1103), а не между «е» и «ж». Для сортировки с учетом правил
  конкретного языка нужны специальные средства (например, `locale.strxfrm`).

Сравнить строку с числом по порядку нельзя — возникнет `TypeError`:

```python
print("10" < 9)
# TypeError: '<' not supported between instances of 'str' and 'int'
```

## 3. Истинность строк

В условиях и логических операциях строка ложна (`False`), только если она
**пустая**. Любая непустая строка истинна — **даже** `"0"`, `"False"` или
строка из одних пробелов:

```python
print(bool(""))       # False
print(bool("a"))      # True
print(bool(" "))      # True
print(bool("0"))      # True
print(bool("False"))  # True
```

Поэтому для проверки «пользователь что-нибудь ввел?» часто пишут так:

```python
user_input = ""

if user_input:
    print("Got input")

else:
    print("Empty input")  # Empty input
```

Как и для других типов, операторы `and` и `or` возвращают **один из
операндов** (а не `bool`). Для строк это дает удобный прием — значение
«по умолчанию» для пустой строки:

```python
name = ""
display_name = name or "anonymous"

print(display_name)         # anonymous
print("hello" and "world")  # world
print("" and "world")       # (пустая строка)
```

---

## Вывод

- `==` и `!=` сравнивают строки **посимвольно и с учетом регистра**; строка
  никогда не равна объекту другого типа. Для сравнения строк используют
  `==`, а не `is`.
- `<`, `>`, `<=`, `>=` сравнивают строки **лексикографически по кодам
  символов Unicode**: сравнивается первая пара различающихся символов, а
  префикс считается меньшей строкой.
- Следствия: заглавные буквы «меньше» строчных, цифры сравниваются как
  символы (`"10" < "9"`), а порядок букв в таблице Unicode может не совпадать
  с алфавитным.
- Пустая строка ложна, любая непустая — истинна (в том числе `"0"` и `" "`).
