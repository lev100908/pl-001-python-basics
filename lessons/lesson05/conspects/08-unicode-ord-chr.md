# Unicode: `ord()`, `chr()` и юникод внутри строк

> **Главная мысль.** Строка в Python — это последовательность **символов
> Unicode**. Каждому символу в стандарте Unicode сопоставлено целое число
> — **кодовая позиция (code point)**. Встроенные функции `ord()` и `chr()`
> переводят символ в его код и обратно.

---

## 1. Что такое Unicode

Компьютер хранит только числа, поэтому для работы с текстом каждому
символу нужно присвоить номер. **Unicode** — международный стандарт,
который делает это для символов практически **всех письменностей мира**
(а также математических знаков, стрелок, эмодзи и так далее). Номер символа
в этом стандарте называется **кодовой позицией (code point)** и
записывается как `U+` и шестнадцатеричное число: например, `U+0041` — это
латинская буква `A`, `U+20AC` — знак евро `€`.

Допустимые кодовые позиции лежат в диапазоне от `0` до `0x10FFFF`
(то есть до 1 114 111 включительно). Первые 128 символов (`0`–`127`) совпадают с таблицей ASCII —
латинские буквы, цифры, знаки препинания и управляющие символы.

Главное, что нужно запомнить: **строка `str` в Python — это последовательность
кодовых позиций Unicode, а не байтов**. Каждый элемент строки —
один такой символ, независимо от того, сколько места он займет при записи в файл
(как именно символы превращаются в байты — вопрос **кодировки**, например,
UTF-8; она нужна при работе с файлами и сетью, но не при работе со
строками в программе).

---

## 2. Функция `ord()`: из символа в код

`ord(char)` принимает строку **ровно из одного символа** и возвращает
целое число — его кодовую позицию:

```python
print(ord("A"))  # 65
print(ord("a"))  # 97
print(ord("0"))  # 48
print(ord("€"))  # 8364
```

Если длина строки не равна `1`, возникает `TypeError`:

```python
print(ord("ab"))
# TypeError: ord() expected a character, but string of length 2 found
```

---

## 3. Функция `chr()`: из кода в символ

`chr(code)` выполняет обратное преобразование — принимает целое число и
возвращает **строку из одного символа**:

```python
print(chr(65))      # A
print(chr(97))      # a
print(chr(8364))    # €
print(chr(0x20ac))  # € -- число можно записать и в шестнадцатеричном виде
```

Функции `ord()` и `chr()` — взаимно обратные:

```python
print(chr(ord("Z")))   # Z
print(ord(chr(1234)))  # 1234
```

Если число выходит за допустимый диапазон, будет `ValueError`:

```python
print(chr(-1))
# ValueError: chr() arg not in range(0x110000)

print(chr(0x110000))
# ValueError: chr() arg not in range(0x110000)
```

### Для чего это используется

Так как буквы алфавита в таблице идут **подряд**, с кодами можно
выполнять арифметику. Например, чтобы получить следующую букву или
буквы по порядку:

```python
print(chr(ord("a") + 1))    # b
print(ord("z") - ord("a"))  # 25 -- расстояние между буквами

first_letters = [chr(code) for code in range(ord("a"), ord("a") + 5)]

print(first_letters)  # ['a', 'b', 'c', 'd', 'e']
```

Для русского и других алфавитов все работает аналогично, но нужно
учитывать расположение символов в таблице.

## 4. Юникод внутри строк

### Символы прямо в литерале

Поскольку строки Python — Unicode, символы любых алфавитов можно писать
в литерале напрямую, если ваш редактор позволяет их ввести:

```python
print("€ £ ¥")        # € £ ¥
print("π ≈ 3.14159")  # π ≈ 3.14159
print("→ ✓ ★")        # → ✓ ★
```

### Длина строки — это количество кодовых позиций

`len()` считает **кодовые позиции**, а не то, что человек видит на экране
как один «символ». Эмодзи — это один символ Unicode, поэтому `len`
возвращает `1`:

```python
print(len("😀"))  # 1
```

Но некоторые «видимые» символы состоят из нескольких кодовых позиций —
например, буква с диакритическим знаком может быть записана как
**базовая буква + отдельный комбинирующий знак**:

```python
composed = "\u00e9"     # é -- один символ
decomposed = "e\u0301"  # e + комбинирующий акут -- выглядит так же, но два символа

print(composed, decomposed)            # é é
print(len(composed), len(decomposed))  # 1 2
print(composed == decomposed)          # False -- строки разные, хотя выглядят одинаково
```

---

## Вывод

- Строка `str` — последовательность **кодовых позиций Unicode**; каждый
  символ имеет номер от `0` до `0x10FFFF`. Преобразование в байты
  (кодировка, например UTF-8) происходит только при записи в файл или
  передаче по сети.
- `ord(char)` возвращает код символа (аргумент — строка из **одного**
  символа), `chr(code)` — символ по коду; функции взаимно обратны.
- Благодаря тому, что буквы алфавита идут в таблице подряд, с кодами можно
  выполнять арифметику (сдвиги букв, генерация алфавита), но для смены
  регистра следует использовать методы строк.
- Символы Unicode можно писать в литерале напрямую.
- `len()` считает кодовые позиции, а не «видимые» символы: один и тот же
  текст может быть записан по-разному.
