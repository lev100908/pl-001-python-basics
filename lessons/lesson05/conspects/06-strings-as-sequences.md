# Строки как последовательности

> **Главная мысль.** Строка — полноценная **последовательность**, поэтому все
> общие операции из конспекта про последовательности (`len()`, `in`, `+`, `*`,
> индексы, срезы, обход в цикле) работают и для нее. Отличия определяются
> двумя особенностями строки: ее элементы — строки длиной `1`, а сама она
> **неизменяема**. Из-за этого `in` для строк проверяет **подстроку**, срез
> всегда возвращает строку, а изменить символ «на месте» нельзя.

---

## 1. Длина: `len()`

`len()` возвращает количество символов в строке (подробнее о том, что именно
считается «символом», — в конспекте про Unicode):

```python
print(len("python"))  # 6
print(len(""))        # 0
print(len("a b"))     # 3 -- пробел тоже символ
```

---

## 2. Проверка вхождения: `in`, `not in`

Для списков и кортежей `in` проверяет, есть ли среди элементов объект с
указанным значением. Для строк оператор `in` работает **шире**: он проверяет,
содержится ли **подстрока** (одна или несколько символов подряд) в строке:

```python
text = "hello, world"

print("h" in text)            # True -- символ
print("world" in text)        # True -- подстрока
print("hello world" in text)  # False -- нет такой подстроки: в тексте есть запятая
print("planet" not in text)   # True
```

Сравнение **регистрозависимо** (`"Hello" in "hello"` — `False`), а пустая
строка по определению содержится в любой строке:

```python
print("Hello" in "hello")  # False
print("" in "hello")       # True
```

Обратите внимание на разницу с другими последовательностями: для списка
`"ell" in ["hello"]` вернет `False`, потому что единственный элемент списка —
это `"hello"`, а не `"ell"`.

---

## 3. Конкатенация: `+`

Оператор `+` склеивает две строки в **новую** строку: сначала идут символы
левого операнда, затем — правого. Исходные строки не меняются:

```python
first_part = "Hello, "
second_part = "world"

print(first_part + second_part)  # Hello, world
print(first_part)                # Hello, -- исходная строка не изменилась
```

Как и у других последовательностей, операнды должны быть **одного типа**.

### Составное присваивание `+=`

Поскольку строка неизменяема, `text += "abc"` **не дописывает** символы в
существующий объект, а создает новую строку и привязывает к ней имя:

```python
text = "abc"
identity_before = id(text)

text += "def"

print(text)                         # abcdef
print(id(text) == identity_before)  # False -- новый объект
```

> Если нужно собрать строку из **многих** частей в цикле, многократный `+=`
> на больших объемах данных неэффективен: на каждом шаге создается новая
> строка. Правильный способ — накопить части в списке и объединить их
> методом `join()` (см. конспект про разбиение и объединение).

---

## 4. Повторение: `*`

Оператор `*` повторяет строку заданное **целое** количество раз и
возвращает новую строку. Если количество повторений неположительное,
результат — пустая строка:

```python
print("ab" * 3)   # ababab
print("-" * 20)   # --------------------
print("ab" * 0)   # (пустая строка)
print("ab" * -2)  # (пустая строка)
```

Типичное применение — разделительные линии и отступы при выводе:

```python
title = "Report"

print(title)
print("=" * len(title))
```

Вывод:
```
Report
======
```

`*=` работает аналогично `+=`: создается новая строка.

---

## 5. Индексы

Обращение по индексу работает так же, как и у списка: индексы начинаются с
`0`, отрицательные отсчитываются с конца, а выход за границы приводит к
`IndexError`. Результат — **строка длиной `1`**:

```python
word = "python"

print(word[0])              # p
print(word[-1])             # n
print(word[len(word) - 1])  # n -- последний символ через длину

print(word[10])
# IndexError: string index out of range
```

Присвоить символу новое значение нельзя — строки неизменяемы:

```python
word[0] = "P"
# TypeError: 'str' object does not support item assignment
```

---

## 6. Срезы

Срез `text[start:stop:step]` работает по тем же правилам, что и у списков
(границы можно опускать, отрицательные индексы отсчитываются с конца,
выход за границы не вызывает ошибки), но результат — всегда **новая
строка**, даже если в нее попал один символ или не попало ни одного:

```python
text = "0123456789"

print(text[2:5])    # 234
print(text[:3])     # 012
print(text[7:])     # 789
print(text[::2])    # 02468
print(text[-3:])    # 789
print(text[5:100])  # 56789 -- ошибки нет
print(text[2:3])    # 2 -- строка из одного символа
print(text[100:])   # (пустая строка)
```

Срез с шагом `-1` — самый короткий способ **развернуть** строку:

```python
word = "python"

print(word[::-1])  # nohtyp
```

Срезы со строками часто используют для разбора текста по фиксированным
позициям — например, чтобы выделить расширение файла или год из даты:

```python
file_name = "report.txt"
date = "2024-05-17"

print(file_name[-3:])  # txt
print(date[:4])        # 2024
```

---

## 7. Итерируемость

Строку можно обойти в цикле `for` — по символам, слева направо:

```python
for char in "abc":
    print(char)
```

Вывод:
```
a
b
c
```

---

## Вывод

- Строка — последовательность: для нее работают `len()`, `in`, `+`, `*`,
  индексы, срезы и обход в цикле.
- `in` для строки проверяет **подстроку**, а не отдельный элемент: `"ell" in
  "hello"` — `True`.
- `+` и `*` создают **новые** строки; `+=` тоже не меняет объект на месте.
- Индекс и срез строки всегда возвращают **строку** (при этом срез не вызывает
  `IndexError`); присваивание по индексу невозможно — `TypeError`.
- Срез `[::-1]` разворачивает строку; `list()`, `tuple()`, `sorted()`
  превращают строку в коллекцию символов.
