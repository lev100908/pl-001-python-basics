# Форматирование строк: f-строки, `format()` и `%`

> **Главная мысль.** **Форматирование** — это сборка строки из шаблона и
> значений. В Python для этого есть три способа: **f-строки** (современный
> и основной), метод **`str.format()`** (когда шаблон отделен от данных) и
> **форматирование в стиле языка Си** с оператором `%` (устаревший способ,
> который встречается в старом коде и в модуле `logging`). Все три
> умеют управлять тем, как значение превращается в текст, — но
> наиболее выразителен язык спецификаторов формата, общий для f-строк и
> `format()`.

---

## 1. Зачем нужно форматирование

Нужно собрать сообщение вида `Alice is 30 years old` из переменных
разных типов. Конкатенация (`+`) требует приводить числа к строке вручную
и плохо читается; к тому же она не позволяет управлять видом числа
(количество знаков после запятой, ширина колонки и т. д.). Форматирование
решает обе задачи.

```python
name = "Alice"
age = 30

print(name + " is " + str(age) + " years old")  # Alice is 30 years old -- громоздко
```

---

## 2. f-строки

Основной способ форматирования в современном Python (подробное введение — в
конспекте про специальные строки). Выражения записываются прямо внутри
текста, в фигурных скобках `{}`, после выражений можно указать **спецификатор формата** через
двоеточие: `{выражение:спецификатор}`:

```python
name = "Alice"
age = 30

print(f"{name} is {age} years old")           # Alice is 30 years old
print(f"Next year {name} will be {age + 1}")  # Next year Alice will be 31
```

---

## 3. Метод `str.format()`

Метод `format()` вызывается **у строки-шаблона**, внутри которой местами
подстановки служат фигурные скобки `{}`. Значения передаются как аргументы метода. Спецификатор
формата записывается так же, как в f-строках — после двоеточия.

### Позиции и имена

Поля могут быть пронумерованы автоматически (`{}`), явно по позиции
аргумента (`{0}`, `{1}`) или связываться с именем (`{name}`):

```python
print("{} is {} years old".format("Alice", 30))                  # Alice is 30 years old
print("{1} is {0} years old".format(30, "Bob"))                  # Bob is 30 years old
print("{name} is {age} years old".format(name="Carol", age=25))  # Carol is 25 years old
print("{0} {0} {0}".format("echo"))                              # echo echo echo
```

Внутри поля можно обращаться к элементам аргументов по индексу:

```python
point = (3, 4)
names = ["Dave", "Eve"]

print("x={0[0]}, y={0[1]}".format(point))  # x=3, y=4
print("Hi, {0[1]}!".format(names))         # Hi, Eve!
```

### Когда `format()` лучше f-строки

f-строка вычисляется **немедленно**, на месте записи. Если же шаблон
нужно хранить отдельно от данных — например, в константе, в
конфигурации, в файле перевода — или использовать многократно с разными
значениями, `format()` подходит лучше:

```python
GREETING_TEMPLATE = "Hello, {name}! You have {messages_count} new messages."

print(GREETING_TEMPLATE.format(name="Alice", messages_count=5))  # Hello, Alice! You have 5 new messages.
print(GREETING_TEMPLATE.format(name="Bob", messages_count=0))    # Hello, Bob! You have 0 new messages.
```

## 4. Форматирование в стиле языка Си: оператор `%`

Самый старый способ, заимствованный из функции `printf` языка Си. Шаблон —
строка со **спецификаторами**, начинающимися с `%`, а значения передаются
справа от оператора `%` (несколько значений — в кортеже):

| Спецификатор | Значение |
|---|---|
| `%s` | строка (через `str()`) |
| `%r` | строка (через `repr()`) |
| `%d` | целое число |
| `%f` | число с плавающей точкой (по умолчанию 6 знаков после запятой) |
| `%x` | целое в шестнадцатеричном виде |
| `%%` | сам символ `%` |

```python
name = "Alice"
age = 30
score = 92.456

print("%s is %d years old" % (name, age))  # Alice is 30 years old
print("Score: %f" % score)                 # Score: 92.456000
print("Progress: %d%%" % 75)               # Progress: 75%
```

Ловушка этого способа: если значение — **один кортеж**, оператор `%`
воспримет его как набор нескольких значений. Одиночный кортеж нужно
дополнительно обернуть в еще один кортеж:

```python
point = (1, 2)

print("Point: %s" % point)
# TypeError: not all arguments converted during string formatting

print("Point: %s" % (point,))  # Point: (1, 2)
```

Почему стоит знать этот способ, хотя использовать в новом коде его не
рекомендуется:

- он **часто встречается в старом коде** и в учебных материалах;
- он применяется в модуле `logging` стандартной библиотеки:
  `logger.info("User %s logged in", user_name)` — форматирование там
  выполняется «лениво», только если сообщение действительно будет выведено.

---

## 5. Сравнение способов

| Способ | Пример | Когда использовать |
|---|---|---|
| f-строка | `f"{name} is {age}"` | **по умолчанию**: короткий и читаемый код |
| `format()` | `"{name} is {age}".format(name=name, age=age)` | шаблон хранится отдельно от данных или используется повторно |
| `%` | `"%s is %d" % (name, age)` | чтение старого кода, `logging` |

Спецификаторы формата f-строк и `format()` едины и подробно разобраны в
следующих конспектах: **форматирование чисел** и **выравнивание**.

---

## Вывод

- Форматирование собирает строку из шаблона и значений и позволяет
  управлять видом каждого значения.
- **f-строки** — основной способ: `f"{value:spec}"`, выражение
  вычисляется на месте.
- **`str.format()`** нужен, когда шаблон хранится отдельно от данных; поля
  могут быть автоматическими (`{}`), позиционными (`{0}`) или именованными
  (`{name}`).
- **Оператор `%`** — унаследованный из Си способ (`%s`, `%d`, `%f`, `%%`);
  встречается в старом коде и в `logging`.
- Спецификаторы формата (`:.2f`, `:>10`, `:,` и др.) общие для f-строк и
  `format()`.
