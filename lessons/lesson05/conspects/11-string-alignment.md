# Выравнивание строк

> **Главная мысль.** Чтобы вывести данные ровными колонками, текст нужно
> **дополнить до заданной ширины**. В Python это делают двумя способами:
> методами строк `ljust()`, `rjust()`, `center()` — они работают только со
> строками — либо спецификатором формата `<`, `>`, `^`, который
> работает с любыми значениями, в том числе с числами. Если строка уже
> длиннее заданной ширины, она **остается без изменений** — обрезки не
> происходит.

---

## 1. Методы `ljust()`, `rjust()`, `center()`

Эти методы возвращают **новую строку** заданной минимальной ширины,
дополнив исходную символами-заполнителями:

- `ljust(width)` — выравнивание **по левому краю** (заполнитель добавляется справа);
- `rjust(width)` — выравнивание **по правому краю** (заполнитель добавляется слева);
- `center(width)` — выравнивание **по центру**.

Вторым необязательным аргументом можно передать **символ-заполнитель** (по
умолчанию — пробел):

```python
word = "cat"

print(f"[{word.ljust(7)}]")        # [cat    ]
print(f"[{word.rjust(7)}]")        # [    cat]
print(f"[{word.ljust(7, '.')}]")   # [cat....]
print(f"[{word.rjust(7, '*')}]")   # [****cat]
print(f"[{word.center(7, '-')}]")  # [--cat--]
```

Заполнитель — это **ровно один символ**, иначе возникнет `TypeError`:

```python
print("cat".ljust(7, ".."))
# TypeError: The fill character must be exactly one character long
```

Если длина строки не меньше `width`, возвращается строка без изменений:

```python
print("elephant".ljust(3))  # elephant -- строка не обрезается
```

При выравнивании по центру, если количество добавляемых символов нечетное
и не делится поровну, лишний символ может оказаться как слева, так и
справа (зависит от ширины и длины строки) — полагаться на конкретное
поведение не стоит:

```python
print(f"[{'ab'.center(5, '-')}]")   # [--ab-]
print(f"[{'abc'.center(6, '-')}]")  # [-abc--]
```

Методы выравнивания определены **только у строк**.

## 2. Выравнивание в спецификаторе формата

В f-строках и методе `format()` выравнивание задается в спецификаторе
формата. Его формат: `[заполнитель]выравнивание ширина`, где
выравнивание — один из символов:

| Символ | Выравнивание | Умолчание для |
|---|---|---|
| `<` | по левому краю | строк |
| `>` | по правому краю | чисел |
| `^` | по центру | — |

```python
word = "cat"

print(f"[{word:<7}]")  # [cat    ]
print(f"[{word:>7}]")  # [    cat]
print(f"[{word:^7}]")  # [  cat  ]
print(f"[{word:7}]")   # [cat    ] -- строки по умолчанию выравниваются влево
print(f"[{42:7}]")     # [     42] -- а числа -- вправо
```

**Символ-заполнитель** указывается **перед** символом выравнивания (и
может быть любым символом, кроме `{` и `}`):

```python
print(f"[{word:.<7}]")  # [cat....]
print(f"[{word:*>7}]")  # [****cat]
print(f"[{word:-^7}]")  # [--cat--]
```

### Выравнивание вместе с форматом числа

Выравнивание можно сочетать с точностью и типом числа. Полный порядок
частей спецификатора: `[заполнитель]выравнивание ширина .точность тип`.
Сначала форматируется само число (например, `3.14159265` → `3.14`), а уже
потом получившаяся **строка** дополняется до ширины:

```python
pi = 3.14159265

print(f"[{pi:.2f}]")      # [3.14]       -- только точность
print(f"[{pi:10.2f}]")    # [      3.14] -- числа по умолчанию выравниваются вправо
print(f"[{pi:<10.2f}]")   # [3.14      ]
print(f"[{pi:^10.2f}]")   # [   3.14   ]
print(f"[{pi:*>10.2f}]")  # [******3.14]
```

Важно: ширина (`10`) — это ширина **всего результата**, включая точку и
знаки после нее, а не только целой части. Если нарушить порядок частей,
будет `ValueError`:

```python
print(f"[{pi:.2f>10}]")
# ValueError: Invalid format specifier '.2f>10' for object of type 'float'
```

---

## Вывод

- `ljust()`, `rjust()`, `center()` дополняют строку до ширины `width`
  символом-заполнителем (по умолчанию — пробелом). Строка длиннее `width`
  не обрезается.
- Спецификатор формата делает то же самое для **любых** значений:
  `<` — влево, `>` — вправо, `^` — по центру; заполнитель пишется перед
  символом выравнивания.
- Строки по умолчанию выравниваются влево, числа — вправо.
