# Методы изменения регистра

> **Главная мысль.** Методы `lower()`, `upper()`, `capitalize()` и `title()`
> возвращают **новую** строку с измененным регистром букв (исходная строка,
> как и любая другая строка, не меняется). Они нужны, чтобы **нормализовать
> пользовательский ввод** (сравнивать без учета регистра), а также
> привести текст к красивому виду при выводе. Правила регистра работают
> для любых алфавитов, а не только для латиницы.

---

## 1. Мотивация

Регистр букв — частая причина «неожиданных» результатов: для компьютера
`"Yes"`, `"yes"` и `"YES"` — три **разные** строки (см. конспект про
сравнение). Пользователь же считает их одним и тем же ответом. Методы
регистра решают две задачи:

1. **Нормализация данных** — привести строки к единому виду перед
   сравнением, поиском или сохранением: например, имена пользователей,
   адреса электронной почты, команды, введенные с клавиатуры;
2. **Оформление вывода** — сделать заголовки заглавными, имена — с большой буквы и т. п.

```python
answer = "YeS"

print(answer == "yes")          # False
print(answer.lower() == "yes")  # True
```

---

## 2. Основные методы

Во всех примерах ниже методы возвращают **новую строку**, а символы,
не являющиеся буквами (цифры, пробелы, знаки), остаются без изменений.

### `lower()` и `upper()`

- `lower()` — все буквы становятся **строчными**;
- `upper()` — все буквы становятся **заглавными**.

```python
text = "Hello, World 123"

print(text.lower())  # hello, world 123
print(text.upper())  # HELLO, WORLD 123
print(text)          # Hello, World 123 -- исходная строка не изменилась
```

`lower()` чаще всего используют для сравнения и поиска без учета регистра,
а `upper()` — для кодов, обозначений и заголовков, которые должны выделяться:

```python
command = "Start"

if command.lower() == "start":
    print("Starting...")  # Starting...
```

### `capitalize()`

Делает **первую** букву строки заглавной, а **все остальные — строчными**:

```python
print("hello world".capitalize())  # Hello world
print("hELLO wORLD".capitalize())  # Hello world
```

Обратите внимание: остальные буквы **принудительно приводятся к нижнему
регистру**, так что аббревиатуры «портятся»:

```python
print("python and NASA".capitalize())  # Python and nasa
```

Подходит для предложений и коротких слов — например, имен и фамилий,
когда нужно привести ввод к виду «Первая заглавная».

### `title()`

Делает заглавной **первую букву каждого слова**, остальные — строчными.
«Словом» метод считает любую непрерывную последовательность букв:

```python
print("the quick brown fox".title())  # The Quick Brown Fox
print("hello-world".title())          # Hello-World
```

Из-за этого у `title()` есть известные недостатки: любой небуквенный
символ, в том числе апостроф, начинает «новое слово»:

```python
print("they're here".title())  # They'Re Here
print("3rd place".title())     # 3Rd Place
```

Для английского текста этот недостаток обходят функцией `capwords()` из
модуля `string` (она делит текст по пробелам):

```python
import string

print(string.capwords("they're here"))  # They're Here
```

## 3. Регистр и неизменяемость: сохраняйте результат

Частая ошибка новичка — вызвать метод и **не сохранить** результат.
Поскольку строка неизменяема, исходная переменная останется прежней:

```python
name = "alice"

name.capitalize()
print(name)  # alice -- ничего не изменилось

name = name.capitalize()
print(name)  # Alice
```

Методы можно **объединять в цепочку**: каждый следующий применяется к
результату предыдущего:

```python
raw_name = "  aLiCe  "

clean_name = raw_name.strip().capitalize()

print(clean_name)  # Alice
```

---

## Вывод

- Методы регистра возвращают **новую** строку, а не изменяют исходную.
- `lower()` / `upper()` приводят все буквы к строчным / заглавным —
  основной инструмент **нормализации** текста перед сравнением и поиском.
- `capitalize()` делает заглавной первую букву строки, остальные — строчными;
  `title()` — первую букву каждого слова (но ошибается на апострофах и
  дефисах — для английского помогает `string.capwords()`).
- Не забывайте **присваивать результат**: `name = name.lower()`.
