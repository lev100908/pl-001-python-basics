# Пользовательские функции: мотивация, определение и вызов

> **Главная мысль.** **Функция** — именованный блок кода, который можно
> выполнить многократно, обратившись к нему по имени. Функции позволяют не
> повторять один и тот же код, разбивать большую задачу на небольшие понятные
> части и тестировать эти части по отдельности. Пользовательская функция
> создается инструкцией **`def`**: после ключевого слова указываются
> **идентификатор** функции, **список параметров** в круглых скобках (он может
> быть пустым) и **тело** — блок с отступом. Определение функции само по себе
> тело не выполняет: код внутри начинает работать только при **вызове**
> `function_name(...)`.

---

## 1. Зачем нужны пользовательские функции

До этого момента программа представляла собой последовательность
инструкций, которые выполняются сверху вниз. Пока программа маленькая, это
удобно. Но как только задача усложняется, возникают проблемы.

Рассмотрим пример: нужно вывести на экран несколько заголовков в одном и том
же оформлении.

```python
print("=" * 20)
print("Report")
print("=" * 20)

print("=" * 20)
print("Summary")
print("=" * 20)

print("=" * 20)
print("Details")
print("=" * 20)
```

Один и тот же фрагмент скопирован три раза. Если понадобится изменить
оформление (например, заменить `=` на `-`), придется найти и исправить все
копии — легко пропустить одну из них. Эту проблему решают функции:

```python
def print_header(title: str) -> None:
    print("=" * 20)
    print(title)
    print("=" * 20)


print_header("Report")
print_header("Summary")
print_header("Details")
```

Теперь оформление описано **в одном месте**, а использовать его можно
сколько угодно раз.

Основные причины использовать функции:

- **Устранение дублирования (принцип DRY — Don't Repeat Yourself).** Код,
  который встречается несколько раз, выносится в функцию и пишется один раз.
  Ошибку достаточно исправить в одном месте.
- **Декомпозиция.** Сложная задача делится на подзадачи, каждая из которых
  решается отдельной функцией. Программа читается как план действий:
  `read_data()`, `build_report()`, `clean_data()`.
- **Читаемость.** Хорошее имя функции объясняет, *что* делает код, и
  избавляет читателя от необходимости разбираться, *как* он это делает.
- **Повторное использование.** Функцию можно вызывать из разных мест
  программы и даже импортировать в другие модули.
- **Тестируемость.** Небольшую функцию с понятным входом и выходом легко
  проверить отдельно от остальной программы.
- **Изоляция.** Переменные, созданные внутри функции, не «засоряют» остальной
  код (подробнее — в конспектах про пространства имен).

Ранее мы уже пользовались готовыми функциями: `print()`, `len()`, `range()`,
`sorted()`. Они являются **встроенными (built-in)**. Функции, которые пишет
сам программист, называются **пользовательскими (user-defined)**.

## 2. Определение функции: ключевое слово `def`

Синтаксис определения функции:

```python
def function_name(parameter_1: type_1, parameter_2: type_2) -> return_type:
    # тело функции -- блок с отступом
    ...
```

Определение состоит из следующих частей:

| Часть | Что это |
|---|---|
| `def` | ключевое слово, с которого начинается определение функции |
| `function_name` | **идентификатор** функции — ее имя |
| `(parameter_1, parameter_2)` | **список параметров** (может быть пустым — `()`) |
| `:` | двоеточие в конце заголовка, как и у `if`, `for`, `while` |
| тело | блок кода с отступом (4 пробела), который выполняется при вызове |

Инструкция `def` — **исполняемая**. Когда интерпретатор доходит до нее, он:

1. **создает объект-функцию** (в него «упаковывается» тело функции);
2. **связывает** созданный объект с именем функции в текущем пространстве
   имен — точно так же, как присваивание `name = value`.

Простейший пример — функция без параметров:

```python
def say_hello() -> None:
    print("Hello, world!")


say_hello()  # Hello, world!
say_hello()  # Hello, world!
```

### Идентификатор функции

Имя функции — это обычный идентификатор Python, и к нему применяются те же
правила, что и к именам переменных:

- состоит из букв, цифр и символа `_`, не начинается с цифры;
- не совпадает с ключевыми словами (`if`, `for`, `class`, ...);
- регистрозависимость: `Count` и `count` — разные имена.

Соглашения [PEP 8](https://peps.python.org/pep-0008/#function-and-variable-names) для имен функций:

- используется стиль **`snake_case`** — слова в нижнем регистре через
  подчеркивание: `calculate_total`, `is_even`;
- имя должно быть **осмысленным** и, как правило, начинаться с **глагола**,
  так как функция что-то *делает*: `read_file`, `send_message`,
  `count_words`;
- для функций, возвращающих логическое значение, часто используют префиксы
  `is_`, `has_`, `can_`: `is_empty`, `has_access`;
- не стоит давать функциям имена встроенных функций (`sum`, `max`, `len`,
  `list`, `print`): новое определение «перекроет» встроенную функцию в
  текущем модуле.

### Список параметров

В круглых скобках через запятую перечисляются **параметры** — имена, через
которые функция получает данные «снаружи». Внутри тела функции параметры
ведут себя как обычные локальные переменные. Список параметров может быть
**пустым**, как в функции `say_hello` выше.

```python
def greet(name: str, greeting: str) -> None:
    print(f"{greeting}, {name}!")


greet("Alice", "Hello")       # Hello, Alice!
greet("Bob", "Good morning")  # Good morning, Bob!
```

### Параметры и аргументы

Эти два термина часто путают, но они означают разное:

- **параметр (parameter)** — имя в **определении** функции
  (`name`, `greeting` в примере выше);
- **аргумент (argument)** — конкретное значение, которое передается в
  функцию при **вызове** (`"Alice"`, `"Hello"`).

При вызове аргументы связываются с параметрами: внутри `greet("Alice",
"Hello")` параметр `name` ссылается на строку `"Alice"`, а параметр
`greeting` — на строку `"Hello"`.

### Тело функции

Тело — это блок кода с отступом, расположенный после заголовка. Оно
выполняется **каждый раз при вызове** и может содержать любые инструкции:
присваивания, ветвления, циклы, вызовы других функций и даже определения
других функций.

Важно: при **определении** функции тело не выполняется — оно запускается
только при **вызове** (подробнее — в разделах 3 и 4).

```python
def print_even_numbers(limit: int) -> None:
    for number in range(limit):
        if number % 2 == 0:
            print(number)


print_even_numbers(7)
```

Вывод:
```
0
2
4
6
```

Если тело пока не написано, используют инструкцию-заглушку `pass`. Тело
функции не может быть пустым — без `pass` (или другой инструкции) будет
`SyntaxError`:

```python
def not_implemented_yet() -> None:
    pass
```

Вместо `pass` можно использовать и объект **`Ellipsis`**, записываемый как
литерал `...` (три точки). Это обычное выражение-значение, поэтому тело
функции с ним тоже синтаксически корректно. Такой стиль часто встречается
в заглушках и аннотациях типов:

```python
def not_implemented_yet() -> None:
    ...
```

## 3. Вызов функции

**Вызов функции** записывается как имя функции и круглые скобки с
аргументами: `function_name(argument_1, argument_2)`. Когда выполнение
доходит до вызова:

1. вычисляются значения аргументов;
2. аргументы связываются с параметрами;
3. управление переходит в тело функции, и оно выполняется;
4. по завершении тела (или по `return`) управление возвращается в то место,
   откуда функцию вызвали, а сам вызов заменяется **возвращаемым
   значением**.

Круглые скобки обязательны — именно они вызывают функцию. Без скобок мы
получаем сам **объект-функцию**, а не результат ее работы:

```python
def say_hello() -> None:
    print("Hello!")


say_hello()  # Hello! -- функция вызвана
say_hello    # ничего не произошло -- мы просто обратились к объекту-функции

print(say_hello)  # <function say_hello at 0x...>
```

Вызов функции — это **выражение**, поэтому его можно использовать везде, где
допустимо значение: внутри других выражений, в качестве аргумента другой
функции и т. д.

```python
def square(number: int) -> int:
    return number * number


total = square(3) + square(4)

print(total)              # 25
print(square(square(2)))  # 16 -- вызов функции как аргумент другой функции
```

Функция может вызывать другие функции, а те — третьи. Так из небольших
блоков собирается сложная программа:

```python
def square(number: int) -> int:
    return number * number


def sum_of_squares(first_number: int, second_number: int) -> int:
    return square(first_number) + square(second_number)


print(sum_of_squares(3, 4))  # 25
```

## 4. Определение и вызов — это разные действия

При определении функции ее тело **не выполняется** — оно выполнится только
при вызове:

```python
print("before def")


def show_message() -> None:
    print("inside function")


print("after def")

show_message()
```

Вывод:
```
before def
after def
inside function
```

Из этого следуют два важных вывода:

**1. Функцию нужно определить до того, как ее вызывают.** Если вызвать
функцию раньше, чем интерпретатор выполнил ее `def`, имя еще не существует и
возникнет `NameError`:

```python
say_goodbye()  # NameError: name 'say_goodbye' is not defined


def say_goodbye() -> None:
    print("Goodbye!")
```

**2. Внутри тела функции можно обращаться к функциям, определенным ниже** —
лишь бы к моменту *вызова* все нужные имена уже существовали. Имена в теле
функции ищутся в момент выполнения, а не в момент определения:

```python
def first() -> None:
    print("first")
    second()


def second() -> None:
    print("second")


first()
```

Вывод:
```
first
second
```

Функция `first` ссылается на `second`, которая определена позже, но к моменту
вызова `first()` имя `second` уже существует.

## Вывод

- Функция — именованный блок кода, который можно вызывать многократно.
  Функции устраняют дублирование (DRY), позволяют декомпозировать задачу,
  повышают читаемость, допускают повторное использование и независимое
  тестирование.
- Пользовательская функция определяется инструкцией
  `def function_name(parameters):` с телом в виде блока с отступом. Имя
  функции подчиняется правилам идентификаторов и PEP 8 (`snake_case`,
  осмысленное имя, обычно начинающееся с глагола). `def` — исполняемая
  инструкция: она создает объект-функцию и привязывает его к имени.
- **Параметры** — имена в определении функции, **аргументы** — значения,
  передаваемые при вызове. Список параметров может быть пустым.
- Вызов — это имя функции со скобками: `function_name(arguments)`. Без скобок
  получается сам объект-функция.
- При определении функции ее тело не выполняется, оно выполняется при каждом
  вызове. Поэтому функцию нужно определить до вызова.
