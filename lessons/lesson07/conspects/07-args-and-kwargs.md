# Произвольное число аргументов: `*args` и `**kwargs`

> **Главная мысль.** Функция может принимать **произвольное количество
> аргументов**. Параметр со звездочкой **`*args`** «собирает» все лишние
> позиционные аргументы в **кортеж**, а параметр с двумя звездочками
> **`**kwargs`** — все лишние именованные аргументы в **словарь**. Названия
> `args` и `kwargs` — лишь общепринятое соглашение; смысл задают звездочки.
> Те же звездочки при **вызове** функции выполняют обратную операцию —
> **распаковывают** коллекцию в отдельные аргументы: `function(*sequence,
> **mapping)`.

---

## 1. `*args`: произвольное число позиционных аргументов

Если перед именем параметра поставить `*`, то все позиционные аргументы,
которые не были сопоставлены с предыдущими параметрами, объединяются в один
**кортеж (`tuple`)**, и именно этот кортеж становится значением параметра.
Сами аргументы при этом не изменяются: они становятся элементами кортежа,
сохраняя свои типы и порядок следования:

```python
def show_arguments(*args: int) -> None:
    print(args)
    print(type(args))


show_arguments(1, 2, 3)
```

Вывод:
```
(1, 2, 3)
<class 'tuple'>
```

Если лишних аргументов нет, `args` — пустой кортеж `()`. Благодаря этому
можно писать функции, не ограничивающие число аргументов:

```python
def sum_all(*args: float) -> float:
    total = 0

    for number in args:
        total += number

    return total


print(sum_all())               # 0
print(sum_all(1))              # 1
print(sum_all(1, 2, 3, 4, 5))  # 15
```

Так устроены многие встроенные функции: например, `print()` принимает любое
число значений, а `max()` и `min()` — любое число сравниваемых элементов.
Параметр со `*` называют **«сборщиком» позиционных аргументов**.

### `*args` после обязательных параметров

Обычные параметры, стоящие **до** `*args`, получают первые позиционные
аргументы, а остальные «собираются» в кортеж:

```python
def print_with_prefix(prefix: str, *messages: str) -> None:
    for message in messages:
        print(f"{prefix}{message}")


print_with_prefix("> ", "first", "second", "third")
```

Вывод:
```
> first
> second
> third
```

### Строго именованные параметры после `*args`

Параметры, указанные **после** `*args`, становятся строго именованными (по
аналогии с одиночной `*` из предыдущего конспекта): позиционные аргументы
«поглощены» `*args`, поэтому такие параметры можно задать только по имени:

```python
def join_words(*words: str, separator: str) -> str:
    return separator.join(words)


print(join_words("a", "b", "c", separator=" "))  # a b c
print(join_words("a", "b", "c", separator="-"))  # a-b-c
```

### Параметр `*args` может быть только один

В списке параметров функции допускается **не более одного** параметра со
`*`. Первый такой параметр принимает все лишние позиционные аргументы, поэтому
для второго аргументов не остается, а граница между ними не определена.
Интерпретатор не пытается распределить аргументы и сообщает о синтаксической
ошибке уже при определении функции:

```python
def invalid_function(*first_args: int, *second_args: int) -> None:
    pass

# SyntaxError: * argument may appear only once
```

Это же ограничение распространяется на одиночную `*`, разделяющую
позиционные и строго именованные параметры: она также считается параметром со
звездочкой, поэтому сочетать ее с `*args` в одной сигнатуре нельзя. Отдельная
`*` и не требуется: сам параметр `*args` уже делает все следующие за ним
параметры строго именованными (см. выше).

---

## 2. `**kwargs`: произвольное число именованных аргументов

Параметр с двумя звездочками собирает все **лишние именованные** аргументы
(те, которым не соответствует ни один параметр) в **словарь**: ключи — имена
аргументов (строки), значения — переданные значения.

```python
def show_options(**kwargs: int) -> None:
    print(kwargs)
    print(type(kwargs))


show_options(width=800, height=600)
```

Вывод:
```
{'width': 800, 'height': 600}
<class 'dict'>
```

Если лишних именованных аргументов нет, `kwargs` — пустой словарь `{}`.

Типичное применение — функции, принимающие «набор настроек» или «пробрасывающие»
параметры дальше:

```python
def build_tag(tag_name: str, text: str, **attributes: str) -> str:
    attributes_text = "".join(
        f' {name}="{value}"' for name, value in attributes.items()
    )

    return f"<{tag_name}{attributes_text}>{text}</{tag_name}>"


print(build_tag("a", "Link", href="https://python.org", target="_blank"))
# <a href="https://python.org" target="_blank">Link</a>

print(build_tag("p", "Text"))
# <p>Text</p>
```

Параметр `**kwargs` **всегда последний** в списке параметров — после него
не может быть никаких других параметров.

---

## 3. Все виды параметров вместе

В определении функции параметры располагаются в строго определенном
порядке:

```python
def function(
    positional_only: int,
    /,
    normal: int,
    *args: int,
    keyword_only: int,
    **kwargs: int,
) -> None:
    ...
```

1. строго позиционные параметры (до `/`);
2. обычные параметры;
3. `*args` (или одиночная `*`);
4. строго именованные параметры;
5. `**kwargs`.

Порядок присвоения: Python сначала связывает позиционные аргументы
с параметрами слева направо, остаток собирает в `*args`; именованные аргументы
сопоставляет с параметрами по имени, а все, что осталось, собирает в
`**kwargs`.

Если именованный аргумент совпадает с именем параметра, он попадет в этот
параметр, а не в `**kwargs`. Если имя совпадает со *строго позиционным*
параметром, оно попадет в `**kwargs`.

## 4. Распаковка аргументов при вызове

Звездочки можно использовать не только в определении функции, но и **в
вызове** — для обратной операции.

### `*sequence` — распаковка в позиционные аргументы

`*` перед итерируемым объектом распаковывает его элементы в отдельные
позиционные аргументы:

```python
def add_three(first: int, second: int, third: int) -> int:
    return first + second + third


numbers = [1, 2, 3]

print(add_three(*numbers))    # 6 -- то же, что add_three(1, 2, 3)
print(add_three(0, *[5, 6]))  # 11
print(add_three(*range(3)))   # 3
```

### `**mapping` — распаковка в именованные аргументы

`**` перед словарем распаковывает его пары в именованные аргументы (ключи
должны быть строками — именами параметров):

```python
values = {"first": 1, "second": 2, "third": 3}

print(add_three(**values))                        # 6 -- то же, что add_three(first=1, second=2, third=3)
print(add_three(1, **{"second": 5, "third": 6}))  # 12
```

Распаковки можно комбинировать с обычными аргументами и друг с другом в
пределах правил порядка вызова. Если один и тот же параметр получит
значение дважды (например, из `*numbers` и из `**values`), будет
`TypeError`.

---

## 5. Важные замечания

- Названия `args` и `kwargs` — **соглашение**. Технически можно написать
  `*numbers` и `**options`, и работать будет так же. Но в общем случае лучше
  придерживаться стандартных имен, а когда назначение аргументов известно —
  давать содержательные: `*numbers`, `**attributes`.
- `args` — именно **кортеж**, а не список: изменить его нельзя. Если нужен
  список, создайте его явно: `items = list(args)`.
- `kwargs` — **новый словарь** при каждом вызове. Его изменение не влияет на
  словарь, который был распакован при вызове (`function(**my_dict)`).
- Не злоупотребляйте `*args` и `**kwargs`: явная сигнатура с именованными
  параметрами понятнее, ее лучше проверяют инструменты и документация. Их
  стоит использовать, когда функция действительно принимает произвольное
  число однотипных аргументов (`sum_all`).

---

## Вывод

- `*args` в определении функции собирает лишние **позиционные** аргументы в
  **кортеж**; `**kwargs` собирает лишние **именованные** аргументы в
  **словарь**. Имена `args` и `kwargs` — соглашение, смысл задают звездочки.
- Порядок параметров: строго позиционные, `/`, обычные, `*args`, строго
  именованные, `**kwargs`.
- Параметры после `*args` — строго именованные; `**kwargs` всегда последний.
- При вызове `*sequence` распаковывает итерируемый объект в позиционные
  аргументы: каждый элемент становится отдельным аргументом. `**mapping`
  распаковывает словарь в именованные аргументы: каждый ключ становится
  именем параметра, а соответствующее значение — переданным значением.
