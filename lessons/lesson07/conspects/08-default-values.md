# Значения по умолчанию

> **Главная мысль.** Параметру можно задать **значение по умолчанию**
> (`greeting="Hello"`) — тогда соответствующий аргумент становится
> необязательным. Принципиально важный факт: значение по умолчанию
> вычисляется **один раз — в момент выполнения инструкции `def`**, а не при
> каждом вызове, и хранится в самом объекте-функции (`__defaults__`). Для
> неизменяемых значений (числа, строки, `None`) это безопасно, а для
> изменяемых приводит к неожиданным ошибкам (см. следующий конспект).

---

## 1. Значения по умолчанию

Параметру можно присвоить значение прямо в определении функции. Такое значение
называется **значением по умолчанию (default value)**. Если при вызове
аргумент для этого параметра не передан, используется значение по умолчанию.
Если передан — оно игнорируется.

```python
def greet(name: str, greeting: str = "Hello", punctuation: str = "!") -> str:
    return f"{greeting}, {name}{punctuation}"


print(greet("Alice"))                       # Hello, Alice!
print(greet("Alice", "Hi"))                 # Hi, Alice!
print(greet("Alice", punctuation="?"))      # Hello, Alice?
print(greet("Alice", "Good morning", "."))  # Good morning, Alice.
```

Параметры, у которых есть значение по умолчанию, становятся
**необязательными**: их можно не указывать при вызове. При этом можно пропустить
параметр «в середине», указав следующие по имени (`punctuation="?"` выше).

### Порядок параметров

Параметры **без** значений по умолчанию (обязательные) должны идти **перед**
параметрами **со** значениями по умолчанию. Иначе будет `SyntaxError`:

```python
def bad(first: int = 1, second: int) -> None:  # SyntaxError
    pass
```

Причина — позиционная передача: если бы обязательный параметр стоял после
необязательного, интерпретатор не смог бы определить, какому параметру
соответствует каждый позиционный аргумент. Единственное исключение —
строго именованные параметры, рассмотренные в одном из предыдущих конспектов.

### Типичные применения

- флаги и режимы работы: `def sort_items(items, reverse=False)`;
- «разумные» значения: `def connect(host, port=5432, timeout=30)`;
- необязательные настройки: функция `print(*values, sep=" ", end="\n")` —
  пример встроенной функции с параметрами по умолчанию.

## 2. Время вычисления значений по умолчанию

Ключевая особенность, которую нужно усвоить: **значение по умолчанию
вычисляется один раз — в момент выполнения инструкции `def`**, то есть при
*определении* функции. При вызовах выражение заново не вычисляется — просто
берется уже готовый объект.

Убедимся в этом, использовав в качестве значения по умолчанию вызов функции
с побочным эффектом:

```python
def get_default() -> int:
    print("evaluating default")
    return 10


print("before def")


def show(value: int = get_default()) -> None:
    print("value:", value)


print("after def")

show()
show()
show(5)
```

Вывод:
```
before def
evaluating default
after def
value: 10
value: 10
value: 5
```

Сообщение `evaluating default` напечатано **один раз** и до того, как
функция была вызвана, — на этапе выполнения `def`. Повторные вызовы `show()`
используют уже вычисленное значение.

Где хранятся значения по умолчанию? Прямо в объекте-функции, в атрибуте
`__defaults__` (кортеж значений для последних параметров):

```python
print(show.__defaults__)   # (10,)
print(greet.__defaults__)  # ('Hello', '!')
```

---

## Вывод

- Значение по умолчанию (`parameter=value`) делает параметр необязательным.
  Обязательные параметры должны стоять перед необязательными.
- Значения по умолчанию вычисляются **один раз при выполнении `def`** и
  хранятся в `function.__defaults__`; при каждом вызове используется один и
  тот же готовый объект. Поэтому выражение в значении по умолчанию не пересчитывается при вызовах:
  результат, зависящий от момента вызова, таким способом получить нельзя.
