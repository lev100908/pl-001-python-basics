# Символьные таблицы функций и поиск имен

> **Главная мысль.** Прежде чем выполнить функцию, Python **компилирует**
> ее и строит для нее **символьную таблицу (symbol table)** — список всех имен
> тела функции с пометкой, к какому пространству они относятся. Правило
> простое: если имя **присваивается** где-либо в теле функции, оно считается
> **локальным** *во всем теле*. Остальные имена ищутся по цепочке **LEGB**:
> **L**ocal (локальные) → **E**nclosing (объемлющие функции) → **G**lobal
> (модуль) → **B**uilt-in (встроенные).

---

## 1. Символьная таблица функции

Когда интерпретатор встречает инструкцию `def`, он компилирует тело функции в
байт-код. На этом этапе для функции строится **символьная таблица**: каждое
имя, встречающееся в теле, классифицируется заранее — *до* запуска функции.

Правило классификации:

- имя, которому в теле функции **присваивается значение** (через `=`, `+=`,
  `for`, `import`, `def`, `with ... as` и т. д.), а также каждый **параметр**
  — **локальное**;
- имя, которое в теле только **читается** и нигде не присваивается, —
  **нелокальное**: оно будет искаться во внешних областях.

Результат этой классификации хранится в объекте кода функции (атрибут
`__code__`) и доступен для изучения:

```python
rate = 2


def calculate(price: float, count: int) -> float:
    total = price * count
    return total * rate


code = calculate.__code__

print(code.co_varnames)  # ('price', 'count', 'total') -- локальные имена
print(code.co_names)     # ('rate',) -- глобальные имена, которые читаются в теле
```

## 2. Поиск имен: правило LEGB

Когда в теле функции имя **читается**, Python ищет его последовательно в
четырех областях видимости и останавливается на первой найденной:

| Область | Обозначение | Что это |
|---|---|---|
| **L**ocal | локальная | имена текущей функции (параметры и переменные) |
| **E**nclosing | объемлющая | локальные области внешних функций (от ближайшей к дальней) |
| **G**lobal | глобальная | имена верхнего уровня модуля |
| **B**uilt-in | встроенная | `print`, `len`, `int`, ... |

Если имя не найдено ни в одной области — возникает `NameError`.

```python
level = "global"


def outer() -> None:
    level = "enclosing"

    def inner() -> None:
        level = "local"
        print(level)  # local -- найдено в L

    def inner_without_local() -> None:
        print(level)  # enclosing -- в L нет, найдено в E

    inner()
    inner_without_local()


outer()
print(level)  # global -- G
print(len)    # <built-in function len> -- B
```

Поиск идет **изнутри наружу** и останавливается на первом совпадении:
ближайшее определение «закрывает» более далекие (затенение, о котором мы
говорили ранее).

Важно: LEGB описывает **чтение** имени. При **присваивании** имя всегда
становится локальным.

---

## Вывод

- Перед выполнением функции компилятор строит ее **символьную таблицу**:
  параметры и имена, которым присваивается значение в теле, — **локальные**;
  имена, которые только читаются, — внешние. Классификация выполняется до
  запуска и действует на **все** тело функции.
- Поиск имен при чтении идет по правилу **LEGB**: Local → Enclosing → Global →
  Built-in; побеждает ближайшее найденное имя. Если имя не найдено —
  `NameError`.
- Присваивание внутри функции создает локальную переменную.
