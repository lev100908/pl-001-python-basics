# Кортеж (`tuple`): обзор и характеристики

> **Главная мысль.** `tuple` — встроенный **составной** тип данных, очень
> похожий на список: он тоже гетерогенен, ограничен и упорядочен. Главное
> отличие от списка — кортеж **неизменяем (immutable)**: после создания
> его содержимое нельзя поменять. При этом кортеж, как и список,
> **итерируем**.

---

## 1. Кортеж — составной (compound) тип данных

Как и список, `tuple` — **составной** тип данных: объект кортежа хранит
ссылки на другие объекты, а не одно скалярное значение:

```python
empty_tuple = ()
coordinates = (10, 20)

print(coordinates)  # (10, 20)
```

---

## 2. Характеристики кортежа

### Гетерогенность

Кортеж, как и список, **гетерогенен** — может одновременно хранить
объекты разных типов данных:

```python
person_record = ("Alice", 30, True)

print(person_record)  # ('Alice', 30, True)
```

### Ограниченность

Кортеж **ограничен** — количество элементов в кортеже можно узнать
встроенной функцией `len()`, точно так же, как и у списка:

```python
print(len(person_record))  # 3
print(len(()))             # 0
```

### Упорядоченность

Кортеж **упорядочен**: у каждого элемента есть фиксированное положение
(индекс), и порядок элементов не меняется:

```python
rgb_color = (255, 0, 0)

print(rgb_color[0])  # 255 -- первый элемент -- красная составляющая
```

### Неизменяемость

В отличие от списка, кортеж **неизменяем (immutable)**: после создания
нельзя добавить, удалить или заменить элемент кортежа — любая попытка
сделать это приведет к возбуждению исключения `TypeError` (подробнее — в отдельном
конспекте):

```python
rgb_color = (255, 0, 0)

rgb_color[0] = 100
# TypeError: 'tuple' object does not support item assignment
```

### Итерируемость

Кортеж, как и список, **итерируем** — его элементы можно обходить по
одному, например, в цикле `for`:

```python
for value in (1, 2, 3):
    print(value)
```

```
1
2
3
```

---

## 3. В каких задачах используются кортежи

Кортеж уместен там, где нужен набор значений, который **не должен
меняться** после создания, или где важно подчеркнуть, что значение —
единый неделимый «пакет» данных, а не изменяемая коллекция:

- координаты, RGB-цвета и другие «записи» фиксированной структуры, где
  каждая позиция имеет свой смысл (`(x, y)`, `(red, green, blue)`);
- возврат нескольких значений из функции — Python синтаксически
  оформляет это как возврат одного кортежа;
- защита данных от случайного изменения — если по смыслу коллекция не
  должна меняться, кортеж делает это гарантией на уровне типа, а не
  соглашением между разработчиками.

---

## Вывод

- `tuple` — составной тип данных, во многом похожий на список:
  гетерогенен, ограничен, упорядочен, итерируем.
- Главное отличие от списка — кортеж **неизменяем**: изменить его
  содержимое после создания нельзя.
- Кортежи используют там, где набор значений по смыслу — фиксированный
  «пакет» данных, а не изменяемая коллекция: координаты, записи
  фиксированной структуры, возврат нескольких значений из функции, ключи
  словарей.
