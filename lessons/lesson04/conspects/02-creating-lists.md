# Создание списков

> **Главная мысль.** Список можно создать с помощью литералов, используя
> квадратные скобки `[]`, с помощью вызова встроенного объекта `list()`
> из любого итерируемого объекта, а также с помощью **спискового
> включения (list comprehension)** — компактной записи, которая строит
> список из другого итерируемого объекта по заданному правилу,
> опционально с фильтрацией и вложенными циклами.

---

## 1. Списковый литерал

Самый простой способ создать список — перечислить его элементы через
запятую в квадратных скобках:

```python
empty_list = []
single_item_list = [42]
several_items_list = [1, 2, 3, 4, 5]
mixed_list = [1, "two", 3.0, True]
```

Элементами литерала могут быть любые выражения, в том числе другие
списки — так получаются вложенные списки (матрицы, таблицы):

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
```

Завершающая запятая после последнего элемента (как в примере выше) —
необязательна, но допустима: это упрощает добавление новых элементов и
чтение различий в системах контроля версий.

---

## 2. Встроенный объект `list()`

Встроенный объект `list()` создает список из любого **итерируемого**
объекта — строки, кортежа, результата вызова `range`, другого списка и так далее.
Каждый элемент источника становится отдельным элементом нового списка:

```python
list("abc")      # ['a', 'b', 'c']       -- строка -- итерируемая
list((1, 2, 3))  # [1, 2, 3]             -- из кортежа
list(range(5))   # [0, 1, 2, 3, 4]       -- из range
```

Без аргументов `list()` создает пустой список — то же самое, что и `[]`:

```python
list()  # []
```

`list()`, примененный к уже существующему списку, создает **новый,
независимый** список с такими же элементами (поверхностную копию, подробнее
в ноутбуке с практикой). Это не то же самое, что присваивание
`copied_numbers = original_numbers`: присваивание не создает новый список, а
лишь дает второе имя тому же самому объекту, поэтому изменения через одно
имя видны через другое:

```python
original_numbers = [1, 2, 3]
copied_numbers = list(original_numbers)

copied_numbers.append(4)  # добавляет элемент в конец списка (подробнее — в следующих конспектах)

print(original_numbers)  # [1, 2, 3]    -- не изменился
print(copied_numbers)    # [1, 2, 3, 4]
```

## 3. Списковые включения (list comprehensions)

### Общий синтаксис

Списковое включение — это компактная запись для создания списка на основе
другого итерируемого объекта: для каждого элемента источника вычисляется
выражение, и результат становится элементом нового списка. Общая форма:

```
[выражение for переменная in источник]
```

Это эквивалентно обычному циклу `for`, который на каждой итерации
добавляет в список результат вычисления выражения:

```python
squares = [number ** 2 for number in range(1, 6)]

print(squares)  # [1, 4, 9, 16, 25]
```

Списковое включение читается компактнее и обычно работает быстрее, чем
эквивалентный цикл с использованием `append()` (метод, который дописывает элемент в конец
списка; подробно он разбирается в следующих конспектах), поэтому там, где
список строится по простому правилу из источника, включение —
предпочтительный вариант.

### Обычные включения

В выражении можно использовать переменную цикла и вызывать любые функции —
результат не обязан быть таким же типом, как элементы источника:

```python
words = ["python", "list", "tuple"]

word_lengths = [len(word) for word in words]

print(word_lengths)     # [6, 4, 5]
```

### Включения с использованием `if`

После источника можно добавить условие `if` — тогда в результат попадут
только те элементы, для которых условие истинно (остальные пропускаются):

```
[выражение for переменная in источник if условие]
```

```python
numbers = range(1, 11)

even_numbers = [number for number in numbers if number % 2 == 0]

print(even_numbers)  # [2, 4, 6, 8, 10]
```

Эквивалентный обычный цикл:

```python
even_numbers = []

for number in numbers:
    if number % 2 == 0:
        even_numbers.append(number)

print(even_numbers)  # [2, 4, 6, 8, 10]
```

### Включения с вложенными циклами

В одном включении можно использовать несколько `for` подряд — это
эквивалентно вложенным циклам, при этом **правый** `for` меняется быстрее
(соответствует самому вложенному циклу):

```
[выражение for переменная_1 in источник_1 for переменная_2 in источник_2]
```

```python
coordinate_pairs = [(row, column) for row in range(3) for column in range(2)]

print(coordinate_pairs)
# [(0, 0), (0, 1), (1, 0), (1, 1), (2, 0), (2, 1)]
```

Эквивалентный обычный цикл:

```python
coordinate_pairs = []

for row in range(3):
    for column in range(2):
        coordinate_pairs.append((row, column))

print(coordinate_pairs)
# [(0, 0), (0, 1), (1, 0), (1, 1), (2, 0), (2, 1)]
```

Вложенные `for` внутри включения часто применяют, чтобы «развернуть»
список списков в один плоский список:

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

flat_values = [value for row in matrix for value in row]

print(flat_values)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

---

## Вывод

- Списковый литерал `[...]` — самый простой способ создать список из
  заранее известных элементов, в том числе вложенных списков.
- `list()` создает список из любого итерируемого объекта (или пустой
  список без аргументов); примененный к списку, создает независимую
  копию, а не ссылку на тот же объект.
- Списковое включение `[выражение for переменная in источник]` компактно
  строит список из источника и эквивалентно циклу `for` с `append()`.
- Во включение можно добавить `if` для фильтрации элементов источника и
  несколько `for` подряд для работы с вложенными источниками (правый `for`
  меняется быстрее).
