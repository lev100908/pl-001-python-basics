# Последовательности: общие операции на примере списков и кортежей

> **Главная мысль.** Список и кортеж — оба относятся к **последовательностям
> (sequences)**: упорядоченным, ограниченным, итерируемым коллекциям с
> доступом по целочисленному индексу. Поэтому у них много **общих операций**, которые
> работают одинаково вне зависимости от того, список это или кортеж —
> отличаются лишь возможностью изменения содержимого.

---

## 1. Что такое последовательность

**Последовательность** — общее название для типов данных, которые
хранят упорядоченный набор элементов с доступом по целочисленному
индексу. И список, и кортеж (а также, например, строка) — это
последовательности. Изменяемость — не обязательное свойство
последовательности: список — изменяемая последовательность, а кортеж и
строка — неизменяемые. Благодаря общей природе у всех последовательностей
есть набор одинаково работающих операций — рассмотрим их на примере
списка и кортежа.

---

## 2. Длина: `len()`

Количество элементов последовательности (ее длину) можно получить с
помощью встроенной функции `len()`. Эту функцию поддерживают все
последовательности — в том числе список, кортеж и строка:

```python
fruits_list = ["apple", "banana", "cherry"]
fruits_tuple = ("apple", "banana", "cherry")

print(len(fruits_list))   # 3
print(len(fruits_tuple))  # 3
```

---

## 3. Проверка вхождения: `in`, `not in`

Чтобы узнать, встречается ли нужное значение среди элементов
последовательности, не нужно перебирать их вручную — для этого есть
оператор `in`. Он проверяет, содержится ли в последовательности объект с
указанным значением, и работает одинаково как для списков, так и для
кортежей. Оператор `not in` выполняет обратную проверку: он убеждается,
что такого значения в последовательности нет. Результатом обоих
операторов является значение типа `bool` — `True` или `False`:

```python
fruits_list = ["apple", "banana", "cherry"]
fruits_tuple = ("apple", "banana", "cherry")

print("banana" in fruits_list)      # True
print("mango" in fruits_list)       # False
print("mango" not in fruits_tuple)  # True
```

## 4. Конкатенация: `+`

Оператор `+` позволяет объединить две последовательности **одного и того же типа**
в новую, того же типа, что и операнды. Результат строится так: сначала
идут **все элементы левого операнда** в исходном порядке, а сразу за ними —
**все элементы правого операнда**, также в исходном порядке. Элементы
не перемешиваются и не сортируются: длина результата равна сумме длин
операндов:

```python
first_list = [1, 2, 3]
second_list = [4, 5]
print(first_list + second_list)  # [1, 2, 3, 4, 5]

first_tuple = (1, 2, 3)
second_tuple = (4, 5)
print(first_tuple + second_tuple)  # (1, 2, 3, 4, 5)
```

Поскольку порядок операндов определяет порядок элементов, конкатенация
**не коммутативна**: если поменять слагаемые местами, получится другая
последовательность. При этом исходные последовательности не меняются —
создается новый объект:

```python
first_list = [1, 2, 3]
second_list = [4, 5]

print(second_list + first_list)  # [4, 5, 1, 2, 3]
print(first_list)                # [1, 2, 3] -- исходный список не изменился
```

### Составное присваивание `+=`

Для конкатенации существует сокращенная форма — **составное присваивание**
`+=`. Запись `sequence += other_sequence` читается как «добавить в конец
`sequence` элементы `other_sequence`» и внешне равносильна
`sequence = sequence + other_sequence`. Однако то, что происходит «под
капотом», зависит от типа последовательности:

- **список** изменяем, поэтому `+=` **расширяет существующий список на
  месте** (как метод `extend()`), не создавая новый объект;
- **кортеж** неизменяем, поэтому `+=` **создает новый кортеж**, к которому
  перепривязывает имя исходного кортежа.

```python
numbers_list = [1, 2, 3]
list_id_before = id(numbers_list)
numbers_list += [4, 5]

print(numbers_list)                        # [1, 2, 3, 4, 5]
print(id(numbers_list) == list_id_before)  # True  -- тот же объект

numbers_tuple = (1, 2, 3)
tuple_id_before = id(numbers_tuple)
numbers_tuple += (4, 5)

print(numbers_tuple)                         # (1, 2, 3, 4, 5)
print(id(numbers_tuple) == tuple_id_before)  # False -- новый объект
```

## 5. Повторение: `*`

Оператор `*` повторяет последовательность указанное количество раз,
возвращая новый объект того же типа. Количество повторений должно
быть **целым числом** — повторить последовательность, например, 2.5 раза
нельзя (такая попытка приведет к `TypeError`):

```python
print([0] * 4)     # [0, 0, 0, 0]
print((1, 2) * 3)  # (1, 2, 1, 2, 1, 2)

print([0] * 2.5)
# TypeError: can't multiply sequence by non-int of type 'float'
```

Если количество повторений **неположительное** (ноль или отрицательное
число), результатом будет **пустая последовательность** того же типа:

```python
print([1, 2] * 0)   # []
print((1, 2) * -3)  # ()
```

### Составное присваивание `*=`

Аналогичная сокращенная форма есть и для повторения: `sequence *= count`
равносильно `sequence = sequence * count`. Так же, как и с `+=`, поведение
зависит от типа последовательности: список при выполнении составного 
присваивания **изменяется на месте**, а для кортежа создается **новый объект**:

```python
numbers_list = [1, 2]
numbers_list *= 3
print(numbers_list)  # [1, 2, 1, 2, 1, 2]

numbers_tuple = (1, 2)
numbers_tuple *= 3
print(numbers_tuple)  # (1, 2, 1, 2, 1, 2)
```

## 6. Индексы и срезы

Обращение по целочисленному индексу и срезы работают у всех последовательностей по
единым правилам — с той разницей, что срез списка возвращает список, а
срез кортежа — кортеж (подробно рассмотрено в конспектах про каждый тип):

```python
print(fruits_list[0])    # apple
print(fruits_tuple[-1])  # cherry

print(fruits_list[:2])   # ['apple', 'banana']
print(fruits_tuple[:2])  # ('apple', 'banana')
```

---

## 7. Итерируемость

Обе последовательности можно обойти в цикле `for` (подробно — в
конспекте про итерируемость списков): элементы перебираются по очереди,
в том порядке, в котором они хранятся:

```python
for fruit in fruits_list:
    print(fruit)

for fruit in fruits_tuple:
    print(fruit)
```

---

## Вывод

- **Последовательность** — общее название для упорядоченных,
  ограниченных, итерируемых коллекций с доступом по целочисленному индексу. К ним
  относятся список, кортеж, строка и другие типы.
- Общие операции работают одинаково для **всех** последовательностей:
  `len()`, `in` / `not in`, `+` (конкатенация), `*` (повторение),
  индексы и срезы, обход в цикле.
- Примеры в конспекте приведены на списках и кортежах лишь потому, что
  это последовательности — то же самое верно и для остальных представителей.
