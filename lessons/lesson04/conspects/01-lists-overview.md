# Список: обзор и характеристики

> **Главная мысль.** `list` — встроенный **составной** тип данных: объект
> списка хранит внутри себя другие объекты, причем **разных** типов данных
> одновременно. Количество элементов в списке можно узнать с помощью
> встроенной функции `len()`, порядок элементов сохраняется,
> сам список можно **изменять** после создания, а его элементы можно
> обходить в цикле. Именно поэтому список — один из самых универсальных и
> часто используемых типов данных в Python.

---

## 1. Список — составной (compound) тип данных

Все типы данных, рассмотренные раньше (`int`, `float`, `bool`, `str`),
хранят внутри себя одно-единственное значение — они называются
**скалярными** (simple, atomic). `list` устроен иначе: объект списка сам
по себе не значение, а **контейнер**, хранящий ссылки на другие объекты —
элементы списка. Из-за этого `list` называют **составным (compound)**
типом данных, наравне с другими типами данных, которые тоже могут содержать
множество объектов (кортеж, множество, словарь).

```python
empty_list = []
numbers = [10, 20, 30]

print(numbers)  # [10, 20, 30]
```

## 2. Характеристики списка

### Гетерогенность

Список **гетерогенен**: в одном списке одновременно могут храниться
объекты разных типов данных — числа, строки, логические значения, другие
списки и вообще любые объекты. Ничто не заставляет все элементы списка
быть одного типа:

```python
mixed_values = [42, "hello", 3.14, True, None, [1, 2, 3]]

print(mixed_values)  # [42, 'hello', 3.14, True, None, [1, 2, 3]]
```

При этом ничто не мешает создавать и списки, все элементы которых имеют
один и тот же тип данных. Гетерогенность — это возможность, а не
требование: на практике однородные списки встречаются очень часто:

```python
ages = [18, 25, 42]
names = ["Alice", "Bob", "Charlie"]

print(ages)   # [18, 25, 42]
print(names)  # ['Alice', 'Bob', 'Charlie']
```

### Ограниченность

Список **ограничен** — в любой момент времени он хранит конкретное, конечное
количество элементов, которое можно узнать с помощью встроенной функции `len()`:

```python
fruits = ["apple", "banana", "cherry"]

print(len(fruits))  # 3
print(len([]))      # 0
```

### Упорядоченность

Список **упорядочен**: элементы хранятся в том порядке, в котором были
добавлены, и у каждого элемента есть свое **положение (индекс)** в этом
порядке. Порядок не меняется сам по себе — переставить элементы можно
только явной операцией (подробнее — в конспекте про работу с элементами
списка).

```python
ordered_colors = ["red", "green", "blue"]

print(ordered_colors[0])  # red -- первый элемент
print(ordered_colors[2])  # blue -- третий элемент
```

### Изменяемость

Список **изменяем (mutable)**: элементы можно добавлять, удалять и менять
после того, как список уже создан — при этом объект списка остается тем же
самым объектом (его идентичность, которую можно узнать с помощью функции
`id()`, не меняется):

```python
scores = [10, 20, 30]
identity_before = id(scores)

scores.append(40)
scores[0] = 100

print(scores)                         # [100, 20, 30, 40]
print(id(scores) == identity_before)  # True -- это все еще тот же объект
```

### Итерируемость

Список **итерируем** — его элементы можно обойти по одному, например, в
цикле `for`:

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

Вывод:
```
apple
banana
cherry
```

## 3. В каких задачах используются списки

Список — тип данных общего назначения для хранения **набора однотипных
или разнотипных значений, количество и состав которых может меняться** по
ходу выполнения программы. Хотя технически список может хранить объекты
разных типов, на практике его обычно используют для хранения **однотипных
данных** — например, только чисел или только строк. Типичные случаи:

- хранение набора однородных данных — список имен пользователей, оценок,
  товаров в корзине, строк файла;
- накопление результатов в процессе вычислений — например, собрать в
  список все числа, прошедшие проверку в цикле;
- очереди и стеки задач, буферы промежуточных данных;
- представление таблиц и матриц — список списков;
- промежуточный результат между операциями обработки данных (прочитали
  данные, отфильтровали, преобразовали — на каждом шаге получается новый
  список).

Там, где заранее неизвестно точное количество элементов или их нужно
менять после создания, список — естественный выбор.

---

## Вывод

- `list` — встроенный **составной** тип данных: хранит ссылки на другие
  объекты, а не одно значение.
- Список **гетерогенен** (элементы могут быть разных типов), **ограничен**
  (длину можно узнать через `len()`), **упорядочен** (у элементов есть
  фиксированный порядок и индекс), **изменяем** (можно менять содержимое
  после создания) и **итерируем** (элементы можно обходить в цикле).
- Списки используют для хранения наборов значений, количество и состав
  которых может меняться по ходу работы программы.
