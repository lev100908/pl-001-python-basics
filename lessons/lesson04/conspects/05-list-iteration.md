# Итерируемость списка

> **Главная мысль.** Список — итерируемый объект: его элементы можно
> обходить по одному в цикле `for` и передавать в любые функции, которые
> работают с итерируемыми объектами. Обход всегда идет в порядке хранения
> элементов — от начала списка к концу.

---

## 1. Итерируемость списка

Список — **итерируемый (iterable)** объект: у него есть механизм,
позволяющий последовательно, один за другим, получать его элементы. Проще
всего этим механизмом пользоваться через цикл `for`:

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

```
apple
banana
cherry
```

Так как список — итерируемый объект, его можно передавать в любые
встроенные функции и конструкции, которые ожидают итерируемый объект на
входе — например, `list()` (создание нового списка из элементов) или
функции, суммирующие и упорядочивающие элементы:

```python
scores = [85, 92, 78, 90]

print(sum(scores))             # 345 -- сумма элементов
print(max(scores))             # 92  -- наибольший элемент
print(min(scores))             # 78  -- наименьший элемент
print(sorted(scores))          # [78, 85, 90, 92] -- новый отсортированный список
print(list(reversed(scores)))  # [90, 78, 92, 85] -- элементы в обратном порядке
```

При итерировании обход всегда идет **в порядке хранения элементов** —
от начала списка к концу, что еще раз подчеркивает упорядоченность
списка как типа данных.

---

## Вывод

- Список — итерируемый объект: элементы можно обходить в `for`, а сам
  список — передавать в функции, ожидающие итерируемый объект (`sum()`,
  `max()`, `min()`, `sorted()`, `reversed()` и другие).
- Обход списка идет в порядке хранения элементов — от начала к концу.
